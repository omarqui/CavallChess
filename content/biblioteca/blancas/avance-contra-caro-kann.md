## Para empezar
Con `3.e5` cerrás el centro y te quedás con más espacio. El caballo negro pierde su casilla natural (f6) y el negro tiene que buscar juego atacando tu cadena de peones d4–e5, sobre todo con ...c5.

Tu receta es simple: desarrollá el caballo a f3 y el alfil a e2, enrocá y recién después decidí cómo abrir el centro. No hace falta atacar enseguida; el espacio de más es tuyo y no se va.

## Ideas y planes
- **Contra 3...Bf5 (Sistema Short):** Nf3, Be2, enroque y c3. Si el negro cambia en d4, recapturás con el caballo para perseguir al alfil de f5, que es su mejor pieza. Con la pareja de alfiles y f4 sosteniendo e5, el negro queda sin rupturas cómodas.
- **Contra 3...c5:** tomás en c5. El negro recupera el peón con el alfil, pero mientras tanto vos desarrollás con tiempo y dejás el alfil de d3 apuntando a h7.
- Tu peón de e5 es la base de todo: defendelo con piezas (Bf4, Re1) o con el peón f cuando haga falta.
- Las rupturas del negro son ...c5 y ...f6. Si abre con ...f6, la casilla e6 y su rey quedan débiles.

## Consejos
- Cuidá el peón de e5: si cae, se te va el espacio que justifica toda la variante.
- Si la dama negra va a b6 atacando b2, contá si tu alfil de c1 todavía lo defiende antes de mover.
- Contra ...c5, enrocá antes de abrir el centro.
- Cuando el negro enroca corto sin un caballo en f6, mirá si hay un sacrificio en h7.

## Variante: Sistema Short {#sistema-short} [básica]
El plan tranquilo de Nigel Short: desarrollo, enroque y c3. Si el negro abre el centro, vas a buscar su alfil de f5.

```pgn
1. e4 c6 2. d4 d5 3. e5 { [%hint Ganá espacio y quitale al caballo su mejor casilla.] } Bf5 4. Nf3 e6 5. Be2 { [%hint Desarrollá para enrocar rápido; todavía no hace falta pelear por su alfil.] } c5 6. O-O { [%hint Poné el rey a salvo antes de abrir el centro: tu peón de b2 sigue defendido.] Si 6...Qb6, `7.c4` y el centro negro sufre; si 6...cxd4, `7.Nxd4` y el alfil de f5 queda incómodo. } Nc6 7. c3 { [%hint Reforzá la base de tu cadena.] Contra 7...Qb6 o 7...Nge7, tomá en c5 y sostené el peón con b4. } cxd4 8. Nxd4 { [%hint Recapturá con una pieza para ir a buscar su alfil bueno.] Ojo: si el negro toma en e5, hay una trampa. } Nge7 9. Nxf5 { Te quedás con la pareja de alfiles. } Nxf5 10. Bd3 g6 11. Qe2 Bg7 12. f4 { [%hint Sostené tu peón de e5 con otro peón.] }
```

Con f4 tu peón de e5 queda firme y los dos alfiles te dan la ventaja a largo plazo. Seguí con Nd2-f3 y Be3; si el negro rompe con ...f6, cambiá y apuntá a e6.

## Trampa a favor: El peón envenenado de e5 {#peon-envenenado-e5} [club]
En el Sistema Short, después de `8.Nxd4` tu peón de e5 queda sin defensores. Parece un regalo, pero tomarlo con el rey negro en el centro sale caro.

```pgn
1. e4 c6 2. d4 d5 3. e5 Bf5 4. Nf3 e6 5. Be2 c5 6. O-O Nc6 7. c3 cxd4 8. Nxd4 Nxe5?? { El peón parecía gratis. } 9. Bb5+ { [%hint Su rey sigue en el centro: dale jaque para clavarle una pieza.] } Nd7 10. Nxf5 { [%hint Despejá la columna de tu dama hacia d5 sin perder tiempo.] } exf5 11. Qxd5 { Recuperás el peón, atacás b7 y el caballo de d7 sigue clavado. }
```

El negro tiene el rey en el centro, una pieza clavada y peones débiles. Si en lugar de `9...Nd7` el negro se tapa con el otro caballo o mueve el rey, tu ventaja es todavía mayor.

## Variante: Contra 3...c5 {#contra-c5} [club]
El negro ataca tu cadena enseguida, aunque el peón de c gasta dos jugadas en llegar a c5. Tomás el peón y desarrollás con tiempo mientras lo recupera.

```pgn
1. e4 c6 2. d4 d5 3. e5 c5 { Ataque inmediato a la cadena. } 4. dxc5 { [%hint Aceptá el peón: el negro va a perder tiempo para recuperarlo.] Contra 4...Nc6 vale el mismo plan: Nf3, Bb5 y enroque. } e6 5. Nf3 Bxc5 6. Bd3 { [%hint Apuntá tu alfil a h7, donde va a estar el enroque negro.] } Nc6 7. O-O Nge7 8. Bf4 { [%hint Protegé el peón de e5 con una pieza que además mire al flanco de rey.] Si ahora el negro enroca, tenés un sacrificio en h7: mirá la trampa. } Ng6 9. Bg3 O-O 10. Nbd2
```

El peón de e5 te da espacio en el flanco de rey. Si el negro rompe con ...f6 o ...f5, cambiá y apuntá a la casilla e6 y a su enroque debilitado; si no, Nb3 y Re1 completan tu desarrollo.

## Trampa a favor: Sacrificio griego {#sacrificio-griego} [club]
Con tu alfil en d3, el caballo listo para saltar a g5 y ningún caballo negro en f6, el enroque corto del negro puede ser un error grave.

```pgn
1. e4 c6 2. d4 d5 3. e5 c5 4. dxc5 e6 5. Nf3 Bxc5 6. Bd3 Nc6 7. O-O Nge7 8. Bf4 O-O? { Enroca justo donde apuntan tu alfil y tu dama, sin un caballo en f6 que defienda h7. } 9. Bxh7+! { [%hint Su enroque no tiene defensores: entregá una pieza para abrirlo.] } Kxh7 10. Ng5+ { [%hint Seguí con jaque y dejale el camino libre a tu dama.] } Kg8 11. Qh5 { Amenaza mate en h7. } Re8 12. Qh7+ Kf8 13. Qh8+ Ng8 14. Nh7+ Ke7 15. Bg5+ { El alfil da jaque en la diagonal de la dama negra: cuando el rey se corra, te la comés. }
```

Si en `10...Kg6` el rey sale a defenderse, `Qg4` sigue con un ataque muy fuerte; y con `10...Kh6`, `Qg4` amenaza mate. Si el negro no toma el alfil y juega `9...Kh8`, igual ganaste un peón y su rey quedó al descubierto.
