## Para empezar
La Siciliana es la respuesta más popular a `1.e4`, y en la Abierta (`2.Nf3` y `3.d4`) las negras suelen saber mucha teoría. Con `2.c3` cambiás el libreto: **preparás `d4`** para que, si las negras cambian en d4, recaptures con un peón y te quedes con el centro.

Las negras tienen que reaccionar rápido contra tu peón de e4, y lo hacen sobre todo de dos maneras:

- Contra `2...Nf6`, avanzá `3.e5`: el caballo se va a d5 y vos seguís con `4.d4`.
- Contra `2...d5`, cambiá con `3.exd5` y, después de `3...Qxd5`, jugá `4.d4`. La dama negra en el centro va a ser un blanco para tus piezas.
- Desarrollá rápido: `Nf3`, el alfil de casillas claras y el enroque corto.
- Muchas veces te va a quedar un peón aislado en d4. No es una debilidad mientras tus piezas estén activas.

## Ideas y planes
- **Con `2...Nf6`:** tu peón de e5 gana espacio y le saca f6 al caballo. Las negras lo atacan con `...d6` o `...d5`, y su caballo de d5 es la pieza que más molesta: echalo con `Bc4` y `Bb3` o cambialo con `Nc3`.
- **El peón aislado en d4:** detrás de él tus piezas tienen lugar. Caballo en c3, dama hacia f3, g4 o e2, torres en las columnas c, d y e. La ruptura `d5`, bien preparada, abre líneas para todas tus piezas.
- **Qué buscan las negras:** bloquear la casilla d5 con una pieza y cambiar piezas, porque en el final el peón aislado sí se vuelve un problema.
- **Con `2...d5`:** la clave es desarrollar ganando tiempos sobre la dama negra (`Nc3`, `Be3`). El alfil que las negras sacan a g4 se puede consultar con `h3`.
- **Con `2...e6`:** `3.d4 d5 4.e5` te lleva a la Variante del Avance de la Francesa, que tiene su propia ficha.

## Consejos
- La idea de toda la apertura es recapturar en d4 con el peón de c: tenela presente cada vez que las negras cambien.
- Después de `3.e5`, la única buena casilla del caballo negro es d5. Si salta a e4, castigalo con `4.d3`.
- Si las negras se comen tu peón de c3 mientras su caballo está en d5, fijate si tu dama puede tomar ese caballo.
- Con peón aislado, buscá la iniciativa en el medio juego: cada cambio de piezas acerca un final que favorece a las negras.
- Antes de comer un peón del flanco de dama con tu dama, mirá si le abrís una columna a las torres rivales.

## Variante: 2...Nf6 con 5...Nc6 {#nf6-nc6} [básica]
Con `3.e5` echás al caballo y con `4.d4` llegás al centro. Si las negras desarrollan con `5...Nc6`, perseguís al caballo de d5 y terminás con un peón aislado en d4, pero con un juego cómodo.

```pgn
1. e4 c5 2. c3 Nf6 3. e5 { [%hint Echá al caballo de su casilla natural ganando espacio.] El caballo no puede quedarse en f6 y tiene que buscar otra casilla. }
3... Nd5 4. d4 { [%hint Cumplí la idea de la apertura: dos peones en el centro.] Si las negras cambian en d4, recapturás con el peón de c. }
4... cxd4 5. Nf3 { Primero desarrollás: el peón de d4 se recaptura después. Si las negras se comen tu peón de c3, el caballo de d5 queda colgado frente a tu dama. }
5... Nc6 6. Bc4 { [%hint Desarrollá una pieza atacando al caballo centralizado.] }
6... Nb6 7. Bb3 { Desde b3 el alfil apunta a f7 y sigue vigilando d5. }
7... d5 8. exd6 { Capturás al paso. Tu peón de e5 ya no tenía apoyo y las negras iban a atacarlo: así lo cambiás por el de d. }
8... Qxd6 9. O-O Be6 10. Bxe6 { Cambiás el alfil que vigilaba d5, la casilla clave delante de tu futuro peón aislado. }
10... Qxe6 11. Nxd4 Nxd4 12. cxd4 { Ahora sí recapturás con el peón. Queda aislado, pero tus piezas tienen espacio detrás de él. }
12... Qd7 13. Nc3 { [%hint Sumá una pieza que controle la casilla donde las negras quieren bloquear tu peón.] Vigila d5. }
```

Seguí con `Be3`, la dama a f3 o g4 y las torres a las columnas c y e. Si un caballo negro se planta en d5, cambialo con el de c3. La ruptura `d5` es tu arma cuando todas tus piezas estén listas.

## Variante: 2...d5 {#d5} [básica]
Con `2...d5` las negras atacan e4 de inmediato. Cambiás en d5 y, con la dama negra en el centro, desarrollás ganando tiempos.

```pgn
1. e4 c5 2. c3 d5 3. exd5 Qxd5 4. d4 { [%hint Aprovechá que tu peón de c3 sostiene la casilla central y ocupala.] }
4... Nf6 5. Nf3 Bg4 6. Be2 { Tapás la clavada: si el alfil cambia en f3, recapturás con el alfil. }
6... e6 7. h3 { Le preguntás al alfil si se cambia o se retira. }
7... Bh5 8. O-O Nc6 9. Be3 cxd4 10. cxd4 { Te queda el peón aislado en d4. }
10... Be7 11. Nc3 { [%hint Desarrollá una pieza atacando a la que está más expuesta.] La dama negra tiene que moverse otra vez. }
11... Qd6 12. Qb3 { [%hint Mirá qué peón negro se quedó sin defensores cuando salió el alfil de c8.] Ataca b7. }
12... O-O 13. Rac1 { Comer en b7 no gana nada y le abre la columna b a las torres negras. Mejor llevás la torre a la columna c, que se abre en cuanto se mueva tu caballo de c3. }
```

Es una posición típica de peón aislado. Seguí con `Rfd1` y buscá el salto `Ne5`; si el alfil negro sigue en h5, `g4` lo echa. Con las piezas listas, la ruptura `d5` abre el juego.

## Variante: 2...Nf6 con 5...e6 {#nf6-e6} [club]
Con `5...e6` las negras sostienen al caballo de d5 con un peón. Ahora recapturás en d4 enseguida y te quedás con dos peones en el centro.

```pgn
1. e4 c5 2. c3 Nf6 3. e5 Nd5 4. d4 cxd4 5. Nf3 e6 6. cxd4 { Dos peones en el centro: d4 y e5. }
6... d6 7. Bc4 { [%hint Desarrollá el alfil presionando al caballo de d5.] }
7... Nc6 8. O-O Be7 9. Qe2 { La dama cuida el alfil de c4 y respalda el peón de e5 por la columna e. }
9... O-O 10. Nc3 { [%hint Desafiá a la pieza que bloquea el centro.] }
10... Nxc3 11. bxc3 { El peón de c3 vuelve a sostener d4 y la columna b queda abierta para tus torres. }
11... dxe5 12. dxe5 { El peón de e5 le saca d6 y f6 a las piezas negras. }
12... Qc7 13. Qe4 { [%hint Llevá la dama hacia el flanco donde enrocó el rival.] Defiende e5 y apunta a h7. }
```

El plan sigue con `Bd3` para sumar el alfil contra h7, `Bf4` para sostener el peón de e5 y una torre a la columna d. Ese peón es el corazón de tu posición: si las negras lo ganan, su juego mejora mucho.

## Variante: 2...e6, al Avance de la Francesa {#e6} [club]
Si las negras responden `2...e6`, jugá `3.d4` y, después de `3...d5`, avanzá `4.e5`: es la misma posición de la Variante del Avance de la Francesa (`1.e4 e6 2.d4 d5 3.e5 c5 4.c3`). Si cambian primero con `3...cxd4`, recapturá con `4.cxd4`.

```pgn
1. e4 c5 2. c3 e6 3. d4 d5 4. e5 { [%hint Cerrá el centro ganando espacio y dejá encerrado al alfil negro de c8.] }
4... Nc6 5. Nf3 Qb6 6. a3 { [%hint Prepará la expansión de tus peones en el flanco de dama.] }
6... c4 7. Nbd2 Na5 8. Rb1 { Defiende b2 y deja libre al alfil de c1. }
8... Bd7 9. Be2 Ne7 10. O-O Nec6 11. Re1 h6 12. Nf1 { El caballo va hacia g3 o e3. }
```

Con el centro cerrado, tus piezas se reubican para jugar en el flanco de rey. Los planes y las otras respuestas de las negras están en la ficha del Avance contra la Francesa.

## Trampa a favor: El caballo sin casillas {#caballo-sin-casillas} [básica]
Después de `3.e5`, si el caballo negro salta a e4 en vez de ir a d5, se queda encerrado.

```pgn
1. e4 c5 2. c3 Nf6 3. e5 Ne4? { Parece una casilla activa, pero el caballo no tiene retirada. }
4. d3 { [%hint Atacá al caballo y contá sus casillas de escape.] No tiene adónde ir: d6 y f6 las controla tu peón de e5, g5 y d2 las cubre tu alfil de c1, y c5 la ocupa un peón negro. }
4... Ng5 5. Bxg5 { Ganaste una pieza. }
```

Si en vez de `4...Ng5` el caballo se lleva un peón con `4...Nxf2` o `4...Nxc3`, lo recapturás igual: las negras quedan con un peón a cambio de una pieza.

## Trampa a favor: El caballo colgado de d5 {#caballo-colgado} [básica]
Después de `5.Nf3`, el peón negro de d4 puede comerse el tuyo de c3. Pero ese peón era el que tapaba la columna d: sin él, tu dama ataca al caballo de d5, que no tiene defensores.

```pgn
1. e4 c5 2. c3 Nf6 3. e5 Nd5 4. d4 cxd4 5. Nf3 dxc3?? { Se come un peón, pero abre la columna d. }
6. Qxd5 { [%hint Mirá qué pieza negra quedó indefensa en la columna que se acaba de abrir.] }
6... cxb2 7. Bxb2 { Las negras tienen dos peones por la pieza, y tu desarrollo es muy superior. }
```

Esta trampa también aparece en el Gambito Smith-Morra rehusado (`2.d4 cxd4 3.c3 Nf6 4.e5 Nd5 5.Nf3`), donde comerse el peón de c3 es todavía más tentador.
