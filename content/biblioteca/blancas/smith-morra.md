## Para empezar
Con `2.d4 cxd4 3.c3` le ofrecés un peón a la Siciliana. Si las negras lo aceptan con `3...dxc3`, recapturás con el caballo y quedás con **mucho más desarrollo**: tus alfiles salen enseguida, enrocás y tus torres van a las columnas c y d, que quedaron abiertas.

El peón de menos es el precio de esa ventaja. Tu tarea es aprovechar el tiempo antes de que las negras terminen de desarrollarse y enroquen tranquilas.

- Después de `4.Nxc3`, el orden típico es `Nf3`, `Bc4`, enroque, `Qe2` y `Rd1`.
- El alfil de c4 apunta a f7: muchas trampas del gambito salen de ahí.
- Si las negras no aceptan el peón, la partida se parece a la Alapin y el material queda igualado.
- No te desesperes por recuperar el peón: lo que importa es que tus piezas trabajen más que las del rival.

## Ideas y planes
- **Las columnas abiertas:** con la dama en e2 y la torre en d1 presionás el peón de d6, el punto débil de las negras. La otra torre va a c1, por la columna c.
- **El avance `e5`:** si las negras sacan el caballo a f6 antes de cerrar la diagonal con `...e6`, el empuje `e5` abre líneas contra su rey y a menudo gana material.
- **Los saltos de caballo:** con los peones negros en d6 o en e6, las casillas d5 y b5 son trampolines para tus caballos. A veces el sacrificio `Nd5` abre la columna e contra el rey negro.
- **El plan de las negras:** enrocar, sacar el alfil de c8 y cambiar piezas. Cada cambio hace que el peón de más pese un poco más.
- **Si rehúsan:** contra `3...Nf6`, `4.e5 Nd5 5.Nf3` lleva a la misma posición de la Alapin; contra `3...d5`, cambiás en d5 y recapturás en d4 con el peón de c.

## Consejos
- Cuando la dama negra está en c7 y un caballo salta a g4, no juegues `h3` sin mirar antes el salto `...Nd4`.
- Con el caballo negro en f6, su peón en d6 y tu alfil en c4, pensá en `e5`.
- Desarrollo antes que material: no gastes tiempos en recuperar el peón.
- Cambiar damas solo te conviene si el rey negro queda expuesto o si ganás algo concreto: sin damas el ataque pierde fuerza y el peón de más pesa.
- En la rehusada con `3...Nf6 4.e5 Nd5 5.Nf3`, si las negras se comen el peón de c3, tu dama gana el caballo de d5.

## Variante: Aceptado, sistema clásico {#aceptado-clasico} [básica] [gambito]
Las negras toman el peón y se desarrollan con `...Nc6`, `...d6`, `...e6` y `...Nf6`. Vos armás el esquema modelo del gambito: alfil en c4, enroque, dama en e2 y torre en d1.

```pgn
1. e4 c5 2. d4 cxd4 3. c3 { [%hint Ofrecé un peón a cambio de desarrollo rápido.] }
3... dxc3 4. Nxc3 { Ya tenés un caballo afuera y los dos alfiles listos para salir. Las negras tienen un peón de más, pero ninguna pieza desarrollada. }
4... Nc6 5. Nf3 d6 6. Bc4 { [%hint Desarrollá el alfil hacia la diagonal que apunta al punto más débil del campo negro.] Apunta a f7. }
6... e6 { Cierra la diagonal hacia f7. }
7. O-O Nf6 8. Qe2 { [%hint Despejá el camino para que una torre llegue a la columna abierta.] }
8... Be7 9. Rd1 { [%hint Poné presión sobre el peón negro de la columna abierta.] La torre mira directo al peón de d6. }
9... e5 { Las negras frenan tu avance e5, pero el peón de d6 queda atrasado y la casilla d5, que ya ningún peón negro puede vigilar, queda para tus piezas. }
10. h3 { Le quitás la casilla g4 al alfil y al caballo negros. }
10... O-O 11. Be3 { Con el centro cerrado, el alfil se ubica en e3 y controla las casillas oscuras del flanco de dama. }
11... Be6 12. Rac1 { [%hint Llevá la última pieza a la otra columna abierta.] Ahora tus dos torres trabajan en columnas abiertas. }
```

Tenés un peón de menos, pero todas tus piezas están en juego. Ideas para seguir: `Bb5` contra el caballo de c6 y `Nb5`, que apunta a d6 y a c7. Si el alfil de e6 cambia en c4, recapturá con la dama.

## Variante: Rehusado con 3...Nf6 {#rehusado-nf6} [básica]
Si las negras no toman el peón y atacan e4 con `3...Nf6`, avanzá `4.e5`. Después de `4...Nd5 5.Nf3` llegás a la misma posición que en la Alapin (`2.c3 Nf6 3.e5 Nd5 4.d4 cxd4 5.Nf3`).

```pgn
1. e4 c5 2. d4 cxd4 3. c3 Nf6 4. e5 { [%hint Echá al caballo ganando espacio.] }
4... Nd5 5. Nf3 { Desarrollás antes de recapturar. Si ahora las negras toman en c3, la columna d se abre y tu dama gana el caballo de d5. }
5... Nc6 6. Bc4 Nb6 7. Bb3 d5 8. exd6 { Capturás al paso: el peón de e5 ya no tenía apoyo de peones. }
8... Qxd6 9. O-O Be6 10. Bxe6 { Cambiás el alfil que vigilaba d5. }
10... Qxe6 11. Nxd4 Nxd4 12. cxd4 Qd7 13. Nc3 { [%hint Controlá la casilla donde las negras quieren bloquear tu peón aislado.] }
```

Tenés un peón aislado en d4 y un desarrollo cómodo, sin peón de menos. Los planes son los de la Alapin: `Be3`, la dama a f3 o g4, torres a las columnas c y e, y la ruptura `d5` cuando todo esté listo.

## Variante: Aceptado con ...e6 y ...a6 {#aceptado-e6-a6} [club] [gambito]
Un esquema muy usado: las negras ponen peones en e6 y a6, sacan el caballo por e7 y preparan `...b5` para echar a tu alfil.

```pgn
1. e4 c5 2. d4 cxd4 3. c3 dxc3 4. Nxc3 Nc6 5. Nf3 e6 6. Bc4 a6 { Prepara ...b5 para ganar un tiempo contra tu alfil. }
7. O-O Nge7 { El caballo va hacia g6 o f5. }
8. Bg5 { [%hint Desarrollá provocando un avance de peón que debilite el enroque.] Presiona e7 y provoca ...h6 o ...f6, que debilitan el enroque negro. }
8... h6 9. Be3 b5 10. Bb3 Na5 { Las negras quieren cambiar tu alfil de b3, que apunta a e6 y a f7. }
11. Rc1 { [%hint No pierdas tiempo salvando al alfil: llevá una torre a la columna abierta.] }
11... Nxb3 12. Qxb3 { Cediste el alfil, pero tu dama queda activa contra e6 y tu torre ya ocupa la columna c. Las negras todavía no enrocaron. }
```

Seguí con `Rfd1` y con `a4` para atacar el peón de b5. Con el rey negro en el centro, el sacrificio `Nd5` contra e6 es una idea típica: calculalo bien antes de jugarlo.

## Variante: Rehusado con 3...d5 {#rehusado-d5} [club]
Con `3...d5` las negras contraatacan en el centro. Cambiás en d5 y recapturás en d4 con el peón de c: el material queda igual y vos jugás con un peón aislado y piezas activas.

```pgn
1. e4 c5 2. d4 cxd4 3. c3 d5 4. exd5 Qxd5 5. cxd4 { Recuperás el peón y el material queda igualado. }
5... Nf6 6. Nf3 e6 7. Nc3 { [%hint Desarrollá ganando un tiempo contra la dama del centro.] }
7... Qd6 8. Bd3 { El alfil apunta al flanco de rey, donde van a enrocar las negras. }
8... Be7 9. O-O O-O 10. Qe2 Nc6 11. Rd1 { [%hint Respaldá desde atrás al peón que algún día va a avanzar.] La torre se ubica detrás del peón de d4: cuando el alfil de d3 se mueva, lo sostiene y apoya la ruptura d5. }
```

Es una posición de peón aislado: buscá juego de piezas con `Bg5`, `Ne5` o `a3` y, cuando esté bien preparada, la ruptura `d5`. Evitá cambiar piezas sin motivo.

## Trampa a favor: El avance e5 {#avance-e5} [básica]
En el sistema clásico, si las negras sacan el caballo a f6 antes de jugar `...e6`, el avance `7.e5` es muy fuerte. Y si toman en e5 con el caballo, pierden la dama.

```pgn
1. e4 c5 2. d4 cxd4 3. c3 dxc3 4. Nxc3 Nc6 5. Nf3 d6 6. Bc4 Nf6 7. e5 { [%hint Con el caballo negro en f6 y la diagonal hacia f7 abierta, empujá un peón con ataque.] Ataca al caballo y amenaza abrir la columna d, donde están las dos damas. }
7... Nxe5?? { Parece que gana un peón, pero después del cambio de caballos quedan expuestos f7 y la dama de d8. }
8. Nxe5 dxe5 9. Bxf7+ { [%hint La dama negra tiene un solo defensor: desvialo con jaque.] }
9... Kxf7 10. Qxd8 { La columna d quedó abierta y la dama negra cae. }
```

Si las negras responden bien con `7...dxe5`, cambiá damas con `8.Qxd8+` y seguí con `Ng5` o `Nb5`: f7 y c7 son difíciles de defender. Contra `7...Ng4`, el avance `8.e6` abre la posición y recuperás el peón en e6.

## Trampa a favor: El caballo colgado de d5 {#caballo-de-d5} [básica]
En la rehusada con `3...Nf6`, las negras pueden sentir la tentación de aceptar el gambito una jugada más tarde. Pero con su caballo en d5, comerse el peón de c3 abre la columna d.

```pgn
1. e4 c5 2. d4 cxd4 3. c3 Nf6 4. e5 Nd5 5. Nf3 dxc3?? { El peón de d4 era el que tapaba la columna d. }
6. Qxd5 { [%hint Mirá qué pieza negra quedó indefensa en la columna que se acaba de abrir.] }
6... cxb2 7. Bxb2 { Dos peones no alcanzan para compensar la pieza, y tu desarrollo es mucho mejor. }
```

## Trampa en contra: La trampa siberiana {#trampa-siberiana} [club]
Una de las trampas más famosas contra el Morra. La dama negra se ubica en c7, en la diagonal que termina en h2, y un caballo salta a g4. Si lo echás con `h3`, el otro caballo salta a d4 y llega el mate.

```pgn
1. e4 c5 2. d4 cxd4 3. c3 dxc3 4. Nxc3 Nc6 5. Nf3 e6 6. Bc4 Qc7 { La dama se para en la diagonal que termina en h2. }
7. O-O Nf6 8. Qe2 Ng4 { La amenaza es ...Nd4: ataca tu dama y, si lo tomás con el caballo de f3, h2 queda sin defensa. }
9. Rd1 { [%hint Antes de echar al caballo de g4, controlá la casilla central a la que quiere saltar el otro caballo.] Si ahora el caballo salta a d4, lo tomás con la torre. }
(9. h3?? { Parece lo más lógico, pero no hace nada contra la amenaza. } Nd4 { Ataca tu dama. } 10. Nxd4 Qh2# { El caballo de f3 era el único defensor de h2. })
```

Después de `9.h3?? Nd4` tampoco sirve mover la dama: `...Nxf3+` y el mate en h2 llegan igual, y si tomás el caballo de g4, el de d4 se lleva tu dama con jaque. Con `9.Rd1`, el salto a d4 se contesta con `Rxd4`. Más adelante podés echar al caballo de g4, pero siempre revisá antes la diagonal de la dama negra.
