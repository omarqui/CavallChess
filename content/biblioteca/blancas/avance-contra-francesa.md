## Para empezar
Con `3.e5` cerrás el centro y te quedás con más espacio. Las negras ya no pueden usar f6 para el caballo y su alfil de casillas claras queda encerrado detrás de e6. A cambio, van a atacar la base de tu cadena de peones, el peón de d4, con `...c5`, `...Nc6` y `...Qb6`.

- Contestá `3...c5` con `4.c3`: si cambian en d4, recapturás con el peón y la cadena sigue entera.
- Después de `5...Qb6`, la dama negra ataca d4 y b2. Con `6.a3` preparás `b4`: ganás espacio en el flanco de dama y le dejás a tu alfil la casilla b2.
- El peón de e5 es tu orgullo: no lo cambies sin motivo.
- Contá siempre cuántas piezas atacan tu peón de d4 y cuántas lo defienden.

## Ideas y planes
- **La cadena d4-e5:** las negras la atacan por la base con `...c5` y sus piezas, y a veces por arriba con `...f6`. Mientras la cadena aguante, vos jugás con más espacio.
- **El plan con `a3` y `b4`:** ganás espacio en el flanco de dama, el alfil sale a b2 para defender d4 y el caballo negro pierde casillas.
- **Si las negras cierran con `...c4`:** ya no presionan d4. Tu plan es reubicar el caballo de d2 por f1 hacia g3 o e3, jugar en el flanco de rey y, en el momento justo, abrir la columna b con `b3`.
- **El caballo negro de f5:** es la pieza que más presiona d4. Cambiarlo con tu alfil de d3 alivia tu centro y le deja a las negras peones débiles.
- **La pieza mala de las negras** es el alfil de c8: no le facilites cambios.

## Consejos
- Con tu alfil en d3, el peón de d4 está más defendido de lo que parece: si las negras lo comen, `Bb5+` destapa el ataque de tu dama.
- Cuando un peón negro llegue a c4 con una torre detrás, no enroques en automático: mirá si puede avanzar a c3 con ataque doble.
- No defiendas b2 con la dama: mejor `Rb1` o `Bb2`.
- Si cambian en d4, recapturá con el peón de c3 siempre que puedas.

## Variante: Con 6...c4 {#c4} [básica]
Las negras cierran el flanco de dama con `6...c4`: dejan de presionar d4 y le cierran el paso a tu `b4`. La partida se vuelve de maniobras.

```pgn
1. e4 e6 2. d4 d5 3. e5 { [%hint Ganá espacio en el centro y quitale una casilla clave al caballo rival.] }
3... c5 4. c3 { [%hint Reforzá la base de tu cadena de peones.] Si cambian en d4, recapturás con un peón. }
4... Nc6 5. Nf3 Qb6 6. a3 { [%hint Prepará la expansión en el flanco de dama.] Amenaza b4, que ganaría espacio y le dejaría b2 a tu alfil. }
6... c4 { Las negras evitan b4 cerrando la posición. }
7. Nbd2 { El caballo vigila b3 y c4. }
7... Na5 8. Rb1 { [%hint Protegé el peón que ataca la dama negra sin atar a tu alfil.] Defiende b2 y deja libre al alfil de c1. }
8... Bd7 9. Be2 Ne7 10. O-O Nec6 11. Re1 { Le deja f1 libre al caballo. }
11... h6 12. Nf1 { [%hint El caballo de d2 ya hizo su trabajo: buscale un camino hacia el flanco de rey.] Va hacia g3 o e3. }
```

La estructura está cerrada. Tu plan: el caballo a g3 o e3, el alfil de c1 a e3 o f4 y más adelante `h4` para ganar espacio en el flanco de rey. Si las negras enrocan largo, la ruptura `b3` contra c4 abre líneas contra su rey.

## Variante: Con 6...Bd7 {#bd7} [club]
Con `6...Bd7` las negras siguen presionando d4 y preparan la torre en la columna c. Vos completás el plan con `b4` y defendés d4 con el alfil.

```pgn
1. e4 e6 2. d4 d5 3. e5 c5 4. c3 Nc6 5. Nf3 Qb6 6. a3 Bd7 7. b4 { [%hint Ganá espacio en el flanco de dama y obligá a las negras a definir su peón de c5.] }
7... cxd4 8. cxd4 Rc8 { La torre ocupa la columna abierta. }
9. Bb2 { El alfil defiende d4. }
9... Na5 { El caballo busca la casilla c4. }
10. Nbd2 { Cubre c4. }
10... Nc4 11. Bxc4 { Cambiás el caballo que se metió en tu campo. }
11... dxc4 12. Rc1 { [%hint Antes de enrocar, controlá la casilla a la que quiere avanzar el peón negro.] Si ahora el peón avanza, lo tomás con el alfil y la torre de c1 lo sostiene. }
```

Ahora el avance del peón negro a c3 ya no gana nada. Seguí con el enroque y con `Ne4`, que apunta a d6 y vigila c3. El peón de c4 quedó lejos de su base y puede volverse un blanco.

## Variante: Con 6...Nh6 {#nh6} [club]
Con `6...Nh6` el caballo va hacia f5 para presionar d4. Vos seguís con `b4`, defendés d4 con el alfil de b2 y, cuando el caballo llega a f5, lo desafiás con el otro alfil.

```pgn
1. e4 e6 2. d4 d5 3. e5 c5 4. c3 Nc6 5. Nf3 Qb6 6. a3 Nh6 { El caballo va a f5, desde donde ataca d4. }
7. b4 cxd4 8. cxd4 Nf5 9. Bb2 { [%hint Sumá un defensor al peón que más atacan las negras.] }
9... Be7 10. Bd3 { [%hint Desafiá a la pieza que más presiona tu centro.] Parece que tu alfil le tapa la defensa de d4 a la dama, pero si las negras comen ese peón, Bb5+ destapa el ataque. }
10... Bd7 11. Bxf5 { Cambiás el caballo más peligroso. }
11... exf5 { Las negras quedan con el peón de d5 aislado y con peones doblados en la columna f. }
12. Nc3 { Presiona el peón de d5. }
12... Be6 13. O-O
```

Tu plan: `Qd3`, el caballo a a4 y después a c5, y las torres a la columna c. El peón aislado de d5 es tu blanco.

## Trampa a favor: El jaque en b5 {#jaque-en-b5} [club]
En la línea de `6...Nh6`, después de `10.Bd3` el peón de d4 parece indefenso: tu alfil tapa a la dama. Si las negras se lo comen, el jaque en b5 destapa el ataque de tu dama sobre d4.

```pgn
1. e4 e6 2. d4 d5 3. e5 c5 4. c3 Nc6 5. Nf3 Qb6 6. a3 Nh6 7. b4 cxd4 8. cxd4 Nf5 9. Bb2 Be7 10. Bd3 Nfxd4? { Tres piezas negras contra dos defensores: parece que gana un peón. }
11. Nxd4 Nxd4 12. Bxd4 Qxd4 13. Bb5+ { [%hint Mové la pieza que tapa a tu dama, y hacelo con jaque.] Jaque, y tu dama ataca a la dama negra por la columna d. }
13... Bd7 14. Bxd7+ { Primero cambiás los alfiles con jaque. }
14... Kxd7 15. Qxd4 { Ganaste la dama. }
```

La misma idea vale en muchas posiciones del Avance: con tu alfil en d3 y la dama en d1, comer en d4 suele costarle caro a las negras. Antes de jugar `Bd3`, fijate que las casillas c4 y b5 estén libres para el jaque.

## Trampa en contra: La horquilla del peón en c3 {#horquilla-c3} [club]
En la línea de `6...Bd7`, después de cambiar en c4 las negras tienen un peón en c4 con la torre de c8 detrás. Enrocar parece lo más natural, pero deja que ese peón avance con ataque doble.

```pgn
1. e4 e6 2. d4 d5 3. e5 c5 4. c3 Nc6 5. Nf3 Qb6 6. a3 Bd7 7. b4 cxd4 8. cxd4 Rc8 9. Bb2 Na5 10. Nbd2 Nc4 11. Bxc4 dxc4 12. Rc1 { [%hint Antes de enrocar, controlá la casilla a la que quiere avanzar el peón negro.] Si ahora el peón avanza, lo tomás con el alfil y la torre de c1 lo sostiene. }
(12. O-O? { Natural, pero deja sin defensa la casilla c3. } c3 { El peón ataca a la vez tu alfil y tu caballo. } 13. Bxc3 Rxc3 { Perdiste una pieza por un peón. })
```

La regla para recordar: cuando un peón rival se mete en tu mitad del tablero con una torre detrás, preguntate qué ataca si avanza una casilla más.
