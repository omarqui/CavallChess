## Para empezar
Con `3.Bb5` atacás al caballo de c6, que es el que defiende el peón de e5. No es una amenaza inmediata, pero esa presión dura toda la partida y condiciona lo que hacen las negras.

El plan blanco es siempre parecido: enroque corto, torre a e1 para cuidar e4, c3 para preparar d4 y h3 para que el alfil negro no clave tu caballo en g4. Cuando todo está listo, jugás d4 y tenés el centro ideal.

- Poné el rey a salvo pronto.
- Armá el centro con c3 y d4, sin apurarte.
- Si las negras echan a tu alfil, retiralo: en la Española es una pieza muy valiosa.

## Ideas y planes
- **El alfil de b3.** Después de ...a6 y ...b5 tu alfil se instala en b3 y apunta a f7. En la Cerrada suele volver a c2 para apoyar el peón de e4.
- **c3, h3 y d4.** El esquema clásico: c3 prepara d4 y le deja c2 al alfil; h3 impide ...Bg4.
- **La maniobra del caballo de b1.** No tiene buena casilla en c3 (taparía el peón de c), así que sale por d2 y va a f1 y g3, rumbo al flanco de rey.
- **Tensión en el centro.** Si las negras cambian en d4, tu pareja de peones e4-d4 te da espacio; si mantienen la tensión, tenés la opción de d5 para ganar terreno.
- **Contra el Marshall.** Si las negras enrocan pronto (`7...O-O`), con `8.h3` o `8.a4` evitás el Ataque Marshall (`8.c3 d5`), que es muy teórico.
- **El Cambio como opción.** Contra `3...a6` existe la Variante del Cambio, `4.Bxc6`: das el alfil por el caballo, doblás los peones negros y buscás un final con mejor estructura. En esta ficha seguimos con `4.Ba4`, que mantiene la tensión, pero el Cambio es una alternativa con menos teoría.

## Consejos
- No cambies en c6 por costumbre: en la línea principal el alfil es tu mejor pieza.
- Después de ...b5, retirá el alfil a b3; si te lo atacan con ...Na5, llevalo a c2.
- Antes de jugar d4, prepará con c3 y h3: si no, ...Bg4 clava tu caballo y presiona d4.
- Contra la Berlinesa, `4.d3` evita el final sin damas que tanto les gusta a las negras y deja muchas piezas en el tablero.
- Cuidado con comerte el peón de e5 apenas se va su defensor: en varias líneas las negras lo recuperan con ventaja.

## Variante: Cerrada (Chigorin) {#cerrada} [básica]
La línea principal. Las negras se desarrollan con ...Nf6 y ...Be7, echan a tu alfil con ...b5 y enrocan. Vos armás el centro con c3, h3 y d4.

```pgn
1. e4 e5 2. Nf3 Nc6 3. Bb5 { [%hint Atacá al defensor del peón de e5.] La Española: presionás al caballo que cuida e5. }
a6 4. Ba4 { [%hint Mantené la presión sin cambiar piezas.] Conservás el alfil y la presión sobre c6. }
Nf6 5. O-O { [%hint Poné el rey a salvo; si te toman el peón de e4, lo vas a recuperar.] }
Be7 6. Re1 { [%hint Defendé el peón de e4 con una pieza que además mira la columna.] }
b5 7. Bb3 d6 8. c3 { [%hint Prepará el avance central y dale una casilla al alfil.] }
O-O 9. h3 { [%hint Quitale al alfil negro la casilla desde donde clavaría tu caballo.] Así ...Bg4 no clava el caballo de f3. }
Na5 { La Chigorin: el caballo echa a tu alfil y le abre paso al peón de c. }
10. Bc2 { El alfil se retira a c2, donde sigue apoyando e4. }
c5 11. d4 { [%hint Con todo preparado, ocupá el centro.] }
Qc7 12. Nbd2 { [%hint Desarrollá el último caballo sin tapar el peón de c.] El caballo sale por d2: después va a f1 y g3, o a b3 si se abre la columna c. }
```

Las negras suelen seguir con `12...cxd4 13.cxd4 Nc6`. Ahí tu caballo va a b3, y tu centro e4-d4 te da más espacio. Es una partida larga de maniobras: no apures el ataque.

## Variante: Berlinesa con 4.d3 {#berlinesa} [club]
Con `3...Nf6` las negras atacan e4 de inmediato. En vez de la línea más teórica, que suele llevar a un final temprano sin damas, con `4.d3` defendés el peón y dejás todas las piezas en el tablero.

```pgn
1. e4 e5 2. Nf3 Nc6 3. Bb5 { [%hint Atacá al defensor del peón de e5.] }
Nf6 4. d3 { [%hint Defendé el peón de e4 con un peón y evitá las simplificaciones.] }
Bc5 5. c3 { [%hint Preparale una retirada al alfil y apoyá un futuro avance central.] }
O-O 6. O-O d6 7. h3 { [%hint Quitale al alfil negro la casilla desde donde clavaría tu caballo.] }
Bb6 8. Re1 Ne7 { El caballo va a g6, hacia tu flanco de rey. }
9. d4 { [%hint Con todo preparado, ganá el centro.] }
Ng6 10. Nbd2 { El mismo plan que en la Cerrada: el caballo de b1 sale por d2. }
```

Si las negras empujan ...c6, el alfil vuelve a f1 o d3. Tenés el centro y más espacio, y la partida se juega como una Cerrada.

## Variante: Gambito Schliemann (3...f5) {#schliemann} [club]
Con `3...f5` las negras contraatacan en el flanco de rey, como un Gambito de Rey con los colores cambiados. La respuesta tranquila `4.d3` le quita la sorpresa.

```pgn
1. e4 e5 2. Nf3 Nc6 3. Bb5 { [%hint Atacá al defensor del peón de e5.] }
f5 4. d3 { [%hint Sostené el peón de e4 sin entrar en complicaciones.] }
fxe4 5. dxe4 Nf6 6. O-O Bc5 7. Bxc6 { [%hint Eliminá al defensor del peón de e5.] }
bxc6 8. Nxe5 { Ganás un peón: sin el peón de f, el centro negro quedó flojo. }
O-O { Las negras usan la columna f y el alfil de c5 contra f2. }
9. Nc3 { [%hint Completá el desarrollo y cuidá el peón de e4.] }
```

Tenés un peón de más. Las negras tienen la columna f abierta y el alfil apuntando a f2: cuidá esa casilla, por ejemplo con el caballo a d3 o el alfil a e3 en el momento justo, y tu ventaja va a pesar.

## Variante: Defensa Bird (3...Nd4) {#bird} [club]
Con `3...Nd4` las negras cambian caballos y dejan un peón en d4 que molesta, pero que también puede quedar débil.

```pgn
1. e4 e5 2. Nf3 Nc6 3. Bb5 { [%hint Atacá al defensor del peón de e5.] }
Nd4 4. Nxd4 { [%hint Cambiá el caballo que saltó al centro.] }
exd4 5. O-O { [%hint Poné el rey a salvo antes de ocuparte del peón de d4.] }
Bc5 6. Bc4 { [%hint Llevá el alfil a la diagonal que apunta a f7.] Sin el caballo de c6, en b5 el alfil no tiene nada que atacar. }
d6 7. d3 c6 8. Bb3 Nf6 9. Bg5 { [%hint Desarrollá el alfil de casillas negras presionando al caballo.] Clavás el caballo de f6 contra la dama. }
```

Con el alfil de b3 apuntando a f7 y el de g5 molestando, seguí con Nd2 y, más adelante, c3 para abrir el juego contra el peón de d4.

## Trampa en contra: La Trampa del Arca de Noé {#arca-de-noe} [club]
Contra `4...d6`, si cambiás en d4 y recuperás el peón con la dama, las negras encierran tu alfil de b3 con ...c5 y ...c4. Es una de las trampas más viejas de la Española.

```pgn
1. e4 e5 2. Nf3 Nc6 3. Bb5 { [%hint Atacá al defensor del peón de e5.] }
a6 4. Ba4 { [%hint Mantené la presión sin cambiar piezas.] }
d6 5. d4 { [%hint Presioná el centro de inmediato.] }
b5 6. Bb3 Nxd4 7. Nxd4 exd4
8. Bd5 { [%hint No recuperes el peón todavía: primero sacá al alfil del lugar donde lo pueden encerrar.] El alfil sale de b3 antes de que lo encierren, y ataca la torre de a8. }
(8. Qxd4?? c5 { Ataca la dama. } 9. Qd5 Be6 10. Qc6+ Bd7 11. Qd5 c4 { El alfil de b3 quedó encerrado por los peones de b5 y c4: lo perdés a cambio de un par de peones. })
Rb8 9. Bc6+ Bd7 10. Bxd7+ Qxd7 11. Qxd4 { Ahora sí recuperás el peón, sin riesgo. }
```

La regla para recordar: con el alfil en b3 y peones negros en a6 y b5, cuidado con la dama en d4 o d5 si las negras pueden jugar ...c5 y ...c4.

## Trampa a favor: La Trampa de Tarrasch {#tarrasch} [club]
En la Abierta (`5...Nxe4`) hay una trampa clásica: si la dama negra va a d7 en el momento equivocado, queda en la misma columna que tu dama y el caballo de e4 pierde a su defensor.

```pgn
1. e4 e5 2. Nf3 Nc6 3. Bb5 { [%hint Atacá al defensor del peón de e5.] }
a6 4. Ba4 { [%hint Mantené la presión sin cambiar piezas.] }
Nf6 5. O-O { [%hint Poné el rey a salvo; si te toman el peón de e4, lo vas a recuperar.] }
Nxe4 { La Abierta: las negras toman el peón. }
6. d4 { [%hint Abrí el centro: el caballo de e4 quedó adelantado.] }
b5 7. Bb3 d5 8. dxe5 { Recuperás el peón y ganás espacio con el peón de e5. }
Be6 9. c3 { [%hint Dale una casilla de retirada al alfil de b3.] }
Be7 10. Re1 { [%hint Presioná el caballo de e4 por la columna.] }
O-O 11. Nd4 { [%hint Saltá al centro con el caballo y apuntá al alfil de e6.] }
Qd7?? { Parece natural, pero deja a la dama negra en la misma columna que la tuya. }
12. Nxe6 fxe6 13. Rxe4 { [%hint El peón que defiende al caballo de e4 no se puede mover.] El peón de d5 está clavado: si toma en e4, tu dama se come a la negra. }
```

Ganaste una pieza. La idea sirve más allá de esta posición: un peón que tapa la línea entre dos damas no puede capturar sin regalar la suya.

## Trampa en contra: La Trampa de Mortimer {#mortimer} [básica]
Contra la Berlinesa con `4.d3`, las negras a veces juegan `4...Ne7`, que parece dejar el peón de e5 sin defensa. Es una invitación: si lo tomás, perdés el caballo.

```pgn
1. e4 e5 2. Nf3 Nc6 3. Bb5 { [%hint Atacá al defensor del peón de e5.] }
Nf6 4. d3 { [%hint Defendé el peón de e4 con un peón y evitá las simplificaciones.] }
Ne7 { El caballo va hacia g6 y deja a e5 sin su defensor. }
5. Nc3 { [%hint No te comas el peón: seguí desarrollándote.] }
(5. Nxe5?? c6 { Ataca al alfil de b5. } 6. Ba4 Qa5+ { Jaque y ataque al caballo de e5 a la vez. } 7. c3 Qxe5 { Las negras ganaron una pieza por un peón. })
c6 6. Bc4 d6 7. d4 { [%hint Ahora sí, jugá por el centro.] }
```

Con el desarrollo completo y d4 jugado, tenés una buena posición. El peón de e5 no se escapa: si las negras lo descuidan de verdad, lo podés tomar más adelante.
