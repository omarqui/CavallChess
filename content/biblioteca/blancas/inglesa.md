## Para empezar
La Inglesa empieza con `1.c4`: en vez de ocupar el centro con un peón, lo controlás desde el costado. El esquema de esta ficha se repite contra casi todo: caballo a c3, peón a g3, alfil a g2 y enroque corto. El alfil de g2 es la pieza estrella: mira d5, el peón de b7 y toda la diagonal larga.

Contra `1...e5` la posición se parece a una Siciliana con los colores cambiados, y vos tenés un tiempo de más. Contra `1...c5` (la Simétrica) o `1...Nf6`, usás el mismo esquema y elegís el momento de romper con d4, b4 o e4.

- Primero el esquema: Nc3, g3, Bg2 y enroque.
- Controlá la casilla d5: es el centro de la Inglesa.
- Tu juego suele estar en el flanco de dama: Rb1, a3 y b4 para ganar espacio.
- Si un caballo negro llega a d5, contá cuántas veces está atacado: muchas veces se puede ganar.

## Ideas y planes
- **Siciliana invertida (`1...e5 2.Nc3 Nf6 3.g3 d5`):** después de `4.cxd5 Nxd5 5.Bg2` el caballo de d5 está atacado dos veces. Cuando se retira a b6, desarrollás con Nf3, enroque y d3, y después avanzás a3 y b4, como en una Siciliana Dragón con los colores cambiados.
- **Inglesa cerrada (`1...e5 2.Nc3 Nc6 3.g3 g6`):** los dos fianchetan. Con d3 y Rb1 preparás b4 y b5 para echar al caballo de c6 y abrir el flanco de dama, donde tu alfil de g2 pesa más.
- **Simétrica (`1...c5`):** con el mismo esquema y Nf3, rompés con d4 para abrir el centro. Después de los cambios en d4 tu dama queda activa, y el alfil de g2 apunta a b7.
- **Contra `1...Nf6` y `2...g6`:** podés armar el sistema Botvinnik, con peones en c4 y e4, el caballo en e2 y enroque. Así controlás d5 con fuerza y tenés planes en los dos flancos: b4 y b5, o f4.

## Consejos
- Después de `5.Bg2` en la Siciliana invertida, contá los atacantes y defensores del caballo de d5 antes de cualquier otra cosa.
- No te apures con d4: en la Inglesa conviene preparar esa ruptura con todas las piezas.
- Si las negras empujan un peón a e4 para echar a tus caballos, fijate si quedó defendido: muchas veces se puede tomar.
- Contra `1...Nf6 2.Nc3 e5`, seguí con `3.g3`: es la misma Siciliana invertida de esta ficha.
- En la Inglesa cerrada, a3 y b4 suelen pesar más que cualquier jugada en el centro.

## Variante: Siciliana invertida {#siciliana-invertida} [básica]
Contra `1...e5` jugás una Siciliana con los colores cambiados. El caballo negro que llega a d5 queda atacado dos veces y tiene que retirarse.

```pgn
1. c4 e5 2. Nc3 { [%hint Desarrollá la pieza que suma control sobre d5.] } Nf6 3. g3 d5 4. cxd5 Nxd5 5. Bg2 { [%hint Atacá por segunda vez al caballo central con una pieza que además se desarrolla.] }
5... Nb6 6. Nf3 { Ataca al peón de e5. } Nc6 7. O-O Be7 8. d3 O-O 9. a3 { [%hint Prepará el avance del peón de b para ganar espacio en el flanco de dama.] }
9... Be6 10. b4 a5 11. b5 { [%hint Echá al caballo que defiende el centro negro.] } Nd4 12. Rb1 { La torre respalda al peón de b5. }
```

La posición está equilibrada y es cómoda para vos: el alfil de g2 domina la diagonal larga y tenés espacio en el flanco de dama. Si el caballo de d4 molesta, cambialo con Nxd4: así se abre la diagonal de tu alfil hacia b7.

## Variante: Inglesa cerrada {#cerrada} [club]
Los dos fianchetan y nadie toca el centro todavía. Tu plan es el flanco de dama: Rb1, a3 y b4.

```pgn
1. c4 e5 2. Nc3 Nc6 3. g3 g6 4. Bg2 Bg7 5. d3 d6 6. Rb1 { [%hint Prepará el avance del peón de b sacando antes la torre de la diagonal del alfil negro.] }
6... a5 7. a3 { [%hint Preparate para empujar igual el peón de b, apoyándolo con otro peón.] } Nf6 8. b4 axb4 9. axb4 O-O 10. b5 { [%hint Echá al caballo que controla d4 y e5.] }
10... Ne7 11. Nf3
```

Con el caballo negro lejos de c6, el flanco de dama es tuyo. Enrocá y seguí con Bb2 o con Nd2 y Nb3, y usá la columna a si se abre del todo.

## Variante: Simétrica {#simetrica} [club]
Contra `1...c5` usás el mismo esquema. Cuando tu rey ya está seguro, rompés con d4 y abrís el juego.

```pgn
1. c4 c5 2. Nc3 Nc6 3. g3 g6 4. Bg2 Bg7 5. Nf3 Nf6 6. O-O O-O 7. d4 { [%hint Rompé en el centro ahora que tu rey está seguro.] } cxd4 8. Nxd4 Nxd4 9. Qxd4 d6
10. Qd3 { [%hint Sacá la dama de la diagonal del alfil de g7 antes de que el caballo negro se mueva y la descubra.] } a6 11. Bd2 Rb8 12. Rac1
```

Tenés espacio y presión en la columna c. Las negras van a buscar `...b5`: respondé con b3 para sostener c4, y llevá la otra torre a d1.

## Variante: Sistema Botvinnik contra 1...Nf6 y ...g6 {#botvinnik} [club]
Contra `1...Nf6` y el fianchetto negro armás el sistema Botvinnik: peones en c4 y e4 que controlan d5. Si las negras juegan `2...e5`, seguí con `3.g3`: es la Siciliana invertida.

```pgn
1. c4 Nf6 2. Nc3 g6 3. g3 Bg7 4. Bg2 O-O 5. e4 { [%hint Sumá otro peón al control de d5, del lado opuesto.] } d6 6. Nge2 { [%hint Desarrollá el caballo sin tapar ni el peón de f ni a tu alfil.] }
6... e5 7. O-O c5 8. d3 Nc6 9. a3 { [%hint Prepará la expansión en el flanco de dama.] } Nd4 10. Rb1 Be6 11. b4
```

El caballo de d4 está fuerte, pero lo podés cambiar con Nxd4 cuando quieras. Tus planes son b5 en el flanco de dama o f4 en el de rey: elegí según dónde estén las piezas negras.

## Trampa a favor: El caballo de d5 atacado dos veces {#caballo-d5} [básica]
Después de `5.Bg2`, el caballo negro de d5 está atacado por tu caballo y por tu alfil, y solo lo defiende la dama. Si las negras desarrollan como si nada, ganás una pieza.

```pgn
1. c4 e5 2. Nc3 Nf6 3. g3 d5 4. cxd5 Nxd5 5. Bg2 Nc6?? { Desarrolla, pero no hace nada por el caballo de d5. } 6. Bxd5 { El caballo estaba atacado dos veces y defendido una sola. }
6... Nb4 7. Bb3 { El alfil se salva y cubre c2. Te quedás con la pieza de más. }
```

Tenés una pieza de ventaja. Desarrollá con d3 y Nf3, enrocá y no te apures: alcanza con no devolverla.

## Trampa a favor: El avance ...e4 sin apoyo {#avance-e4} [club]
En la Siciliana invertida, `5...e4` parece molestar a tu desarrollo, pero el peón queda solo y tu dama lo gana con jaque.

```pgn
1. c4 e5 2. Nc3 Nf6 3. g3 d5 4. cxd5 Nxd5 5. Bg2 e4? { Le quita casillas a tus caballos, pero nadie defiende ese peón. } 6. Qa4+ { [%hint Buscá un jaque que además ataque al peón adelantado.] }
6... c6 7. Qxe4+ Be7 8. Nxd5 cxd5 9. Qxd5 { Dos peones de ventaja. }
```

Con dos peones de más y el alfil de g2 apuntando al flanco de dama, cambiá piezas y simplificá hacia un final.
