## Para empezar
Con `3.d4` atacás el peón de e5 enseguida. Después de `3...exd4 4.Nxd4` tenés un caballo fuerte en el centro, un peón en e4 y líneas abiertas para desarrollar todo rápido.

Las negras tienen dos respuestas principales: `4...Bc5`, que ataca tu caballo, y `4...Nf6`, que ataca tu peón de e4. Contra las dos, en esta ficha cambiás en c6 y aprovechás que los peones negros quedan menos sanos.

- Desarrollá rápido y enrocá corto.
- Vigilá el peón de e4: es el blanco preferido de las negras.
- Cuidá f2: muchas amenazas negras pasan por esa casilla.

## Ideas y planes
- **El cambio en c6.** Con `5.Nxc6` las negras recapturan con un peón y les quedan peones doblados en la columna c. Si toman con el peón de d, tu mayoría del flanco de rey queda sana y la de ellas, en el flanco de dama, no puede crear un peón pasado con facilidad: en los finales eso pesa.
- **El peón de e4.** Es tu ventaja central. Defendelo con Nc3, Bd3 o la dama y no lo cambies sin motivo.
- **La Mieses.** Contra `4...Nf6`, después de `5.Nxc6 bxc6 6.e5` echás al caballo y ganás espacio. Con c4 le quitás d5 al caballo, y tus alfiles van a las diagonales largas: b2 y g2.
- **Cambiar damas no te asusta.** Con una estructura de peones mejor, un final tranquilo suele ser cómodo para vos.

## Consejos
- Después de `4...Bc5 5.Nxc6`, mirá la amenaza `5...Qf6`: ataca f2 con la dama y el alfil. Defendé con la dama antes de desarrollar otra pieza.
- En la Mieses, no te apures por cambiar el peón de e5: es el que les quita casillas a las piezas negras.
- Si un caballo negro ataca a tu dama, antes de moverla fijate si lo podés capturar.
- Contra `4...Qh4`, que ataca e4, `5.Nc3` defiende el peón y desarrolla.
- Si las negras cambian caballos con `4...Nxd4`, retomá con la dama: queda centralizada y sin problemas.
- Cuando las negras recapturan con el peón de b, la columna b queda semiabierta para su torre: vigilá tu peón de b2.

## Variante: Clásica con 6...dxc6 {#clasica-dxc6} [básica]
Las negras atacan tu caballo de d4 con el alfil. Cambiás en c6 y, después de `5...Qf6`, defendés f2 con la dama.

```pgn
1. e4 e5 2. Nf3 Nc6 3. d4 { [%hint Atacá el peón de e5 desde el principio.] Abrís el centro de entrada. }
exd4 4. Nxd4 { [%hint Recuperá el peón con una pieza.] }
Bc5 { Ataca tu caballo de d4. }
5. Nxc6 { [%hint Resolvé la tensión en d4 de forma que las negras queden con peones doblados.] }
Qf6 { Doble amenaza: mate en f2 y recuperar la pieza en c6. [%cal Gf6f2 Gc5f2] }
6. Qd2 { [%hint Antes de desarrollar, frená la amenaza sobre f2.] La dama cubre f2 por la segunda fila. }
dxc6 7. Nc3 Be6 8. Na4 { [%hint Atacá el alfil de c5 para sacarlo de su mejor diagonal.] }
Bd6 9. Bd3 { [%hint Defendé el peón de e4 y prepará el enroque.] }
```

Seguí con el enroque corto y, cuando puedas, f4 para mover tu mayoría de peones del flanco de rey. En un final, esa mayoría sana es tu argumento a largo plazo.

## Variante: Clásica con 6...bxc6 {#clasica-bxc6} [club]
Si las negras recapturan con el peón de b, se quedan con un centro más firme pero con peones doblados y el peón de a aislado.

```pgn
1. e4 e5 2. Nf3 Nc6 3. d4 { [%hint Atacá el peón de e5 desde el principio.] }
exd4 4. Nxd4 { [%hint Recuperá el peón con una pieza.] }
Bc5 5. Nxc6 { [%hint Resolvé la tensión en d4 de forma que las negras queden con peones doblados.] }
Qf6 6. Qd2 { [%hint Antes de desarrollar, frená la amenaza sobre f2.] }
bxc6 { Recapturan hacia el centro. }
7. Bd3 { [%hint Defendé el peón de e4 y prepará el enroque.] }
Ne7 8. O-O O-O 9. Nc3 { Desarrollo completo y el peón de e4 bien cuidado. }
```

Las negras van a buscar ...d5 para abrir el centro. Vos tenés una estructura mejor: Kh1 y f4 son ideas típicas para jugar en el flanco de rey.

## Variante: Mieses (4...Nf6) {#mieses} [club]
Con `4...Nf6` las negras atacan tu peón de e4. Cambiás en c6 y empujás e5: es la línea más ambiciosa contra esta defensa.

```pgn
1. e4 e5 2. Nf3 Nc6 3. d4 { [%hint Atacá el peón de e5 desde el principio.] }
exd4 4. Nxd4 { [%hint Recuperá el peón con una pieza.] }
Nf6 { Ataca el peón de e4. }
5. Nxc6 { [%hint Primero cambiá caballos: así el peón de e4 queda libre para avanzar.] }
bxc6 6. e5 { [%hint Echá al caballo con un peón y ganá espacio.] }
Qe7 { La dama ataca el peón de e5 y lo clava contra tu rey. }
7. Qe2 { [%hint Defendé el peón de e5 y sacá la clavada de la columna.] }
Nd5 8. c4 { [%hint Echá al caballo del centro.] }
Ba6 { Clava tu peón de c4 contra la dama. }
9. b3 { [%hint Sostené el peón de c4 con otro peón.] }
g6 10. Bb2 Bg7 11. g3 O-O 12. Bg2 { Los dos alfiles en las diagonales largas. }
```

Enrocá cuanto antes: las negras van a presionar el peón de e5 con ...Rae8 y el alfil de g7, y con tu rey en el centro eso sería un problema.

## Trampa en contra: El mate en f2 {#mate-en-f2} [básica]
Después de `4...Bc5 5.Nxc6 Qf6`, las negras amenazan mate en f2. Si desarrollás una pieza sin mirar esa amenaza, la partida se termina en el acto.

```pgn
1. e4 e5 2. Nf3 Nc6 3. d4 { [%hint Atacá el peón de e5 desde el principio.] }
exd4 4. Nxd4 { [%hint Recuperá el peón con una pieza.] }
Bc5 5. Nxc6 { [%hint Resolvé la tensión en d4 de forma que las negras queden con peones doblados.] }
Qf6 { Amenaza mate en f2. }
6. Qd2 { [%hint Antes de desarrollar, frená la amenaza sobre f2.] }
(6. Nc3?? { Desarrolla y defiende e4, pero se olvida de f2. } Qxf2# { La dama, apoyada por el alfil de c5, da mate. })
dxc6 7. Nc3 { Ahora sí, con f2 cubierto, desarrollás el caballo. }
```

Antes de cada jugada en esta línea, preguntate qué ataca la dama de f6. Con f2 defendido, las negras solo recuperan la pieza y la partida es normal.

## Trampa a favor: El caballo suelto en f4 {#caballo-en-f4} [básica]
En la Mieses, después de `8.c4` el caballo de d5 tiene que moverse. Ir a f4 parece fuerte porque ataca tu dama, pero el caballo queda sin defensa.

```pgn
1. e4 e5 2. Nf3 Nc6 3. d4 { [%hint Atacá el peón de e5 desde el principio.] }
exd4 4. Nxd4 { [%hint Recuperá el peón con una pieza.] }
Nf6 5. Nxc6 { [%hint Primero cambiá caballos: así el peón de e4 queda libre para avanzar.] }
bxc6 6. e5 { [%hint Echá al caballo con un peón y ganá espacio.] }
Qe7 7. Qe2 { [%hint Defendé el peón de e5 y sacá la clavada de la columna.] }
Nd5 8. c4 { [%hint Echá al caballo del centro.] }
Nf4?? { Ataca tu dama, pero nadie defiende al caballo. }
9. Bxf4 { [%hint Antes de mover la dama, fijate si podés eliminar a la pieza que la ataca.] Eliminás al atacante: la dama negra no puede tomar la tuya porque el peón de e5 está en el medio. }
```

Ganaste una pieza. Es un error muy común: atacar a la dama no sirve de nada si la pieza que ataca se puede capturar gratis.
