## Para empezar
Contra la Italiana con `3...Bc5`, el Gambito Evans ofrece un peón con `4.b4`. Si el alfil lo toma, `5.c3` lo vuelve a echar y prepara `6.d4`. Por un peón conseguís un centro grande, desarrollo rápido y líneas abiertas contra el rey negro.

La idea es simple: cada jugada tuya gana un tiempo o abre una línea. Las negras tienen material de más, pero si se demoran en desarrollarse, el ataque llega antes.

- Atacá el alfil de c5 para desarrollarte con tempo.
- Ocupá el centro con c3 y d4.
- Enrocá rápido y usá las diagonales: el alfil de c4 apunta a f7 y el de c1 puede ir a a3.

## Ideas y planes
- **El alfil a a3.** Desde a3 el alfil de casillas negras controla la diagonal que llega a f8. Si esa diagonal está libre, el rey negro no puede enrocar corto.
- **La dama a b3.** Junto con el alfil de c4 ataca f7, y de paso mira b7.
- **El peón de e5.** Con peones en e4 y d4, el avance e5 echa al caballo de f6 y le quita casillas a todo el flanco de rey negro.
- **El rey en el centro.** Tu ventaja es de tiempo, no de material. Abrí la columna e y llevá las torres al centro antes de que las negras terminen de desarrollarse.
- **No te apures por recuperar el peón.** Si lo recuperás cambiando tus piezas más activas, te quedás sin compensación.
- **Contra el rehúse.** Si las negras no toman el peón y juegan `4...Bb6`, el peón de b4 te da espacio en el flanco de dama, y con a4 molestás al alfil.

## Consejos
- Después de `5.c3`, jugá `6.d4` enseguida: cada tiempo que regalás las negras lo usan para consolidar.
- Con el alfil negro en a5 y tu rey en e1, el peón de c3 está clavado. Enrocá antes de tomar en d4 con ese peón.
- Si las negras se comen el peón de e4 con el caballo, buscá el contragolpe por la columna e o con la dama al centro.
- Contra `...Na5`, que busca cambiar tu alfil de c4, retiralo a una casilla segura si lo necesitás para el ataque.
- Con dos peones de menos no hay vuelta atrás: jugá con energía y no cambies damas sin motivo.
- Contra `6...d6`, `7.Qb3` arma una batería de dama y alfil contra f7; las negras suelen defenderse con `7...Qd7`.
- Contra `6...exd4 7.O-O d6`, también `8.Qb3` es lo más incisivo: presiona f7 junto con el alfil y ataca b7.

## Variante: Aceptado con 5...Ba5 y 7...Nge7 {#aceptado-nge7} [básica] [gambito]
La línea principal. Las negras toman el peón, dejan el alfil en a5 clavando el peón de c3 y desarrollan el caballo por e7 para poder jugar ...d5.

```pgn
1. e4 e5 2. Nf3 Nc6 3. Bc4 Bc5 4. b4 { [%hint Ofrecé un peón del flanco de dama para ganar tiempos contra el alfil.] El Gambito Evans: si el alfil lo toma, lo vas a seguir atacando. }
Bxb4 5. c3 { [%hint Echá al alfil y prepará el avance central.] Ataca al alfil y prepara d4. }
Ba5 { Desde a5 el alfil clava el peón de c3 contra tu rey. }
6. d4 { [%hint Golpeá el centro antes de que las negras se acomoden.] }
exd4 7. O-O { [%hint Sacá el rey de la diagonal del alfil de a5.] Con el rey en e1, el peón de c3 no puede tomar en d4. Enrocado, queda libre. }
Nge7 { Prepara ...d5 para devolver el peón y desarrollarse. }
8. cxd4 d5 9. exd5 Nxd5 10. Ba3 { [%hint Buscá la forma de dejar al rey negro sin enroque.] Desde a3 controla f8: las negras ya no pueden enrocar corto. [%cal Ga3f8] }
Be6 11. Bb5 { Clavás el caballo de c6 contra el rey y sumás presión sobre una posición que no puede enrocar. }
```

Las negras tienen un peón de más, pero el rey sigue en el centro. Seguí con la dama a a4 o b3, el caballo de b1 al juego y las torres a las columnas abiertas.

## Variante: Aceptado con 7...Nf6 {#aceptado-nf6} [club] [gambito]
La respuesta más natural en la práctica: el caballo sale a f6 y ataca el peón de e4. Si las negras lo toman, tenés un contragolpe preparado.

```pgn
1. e4 e5 2. Nf3 Nc6 3. Bc4 Bc5 4. b4 { [%hint Ofrecé un peón del flanco de dama para ganar tiempos contra el alfil.] }
Bxb4 5. c3 { [%hint Echá al alfil y prepará el avance central.] }
Ba5 6. d4 { [%hint Golpeá el centro antes de que las negras se acomoden.] }
exd4 7. O-O { [%hint Sacá el rey de la diagonal del alfil de a5.] }
Nf6 8. cxd4 { Recuperás el peón central, ahora que el peón de c3 ya no está clavado. }
Nxe4 { Las negras se llevan otro peón, pero su rey sigue sin enrocar. }
9. d5 { [%hint Atacá el caballo de c6 con un peón antes de ocuparte del de e4.] El caballo de c6 tiene que irse y deja de cuidar el centro. }
Ne7 10. Qd4 { [%hint Buscá un doble ataque con la dama.] La dama ataca a la vez el caballo de e4 y el peón de g7. [%cal Gd4e4 Gd4g7] }
Nf6 { Defiende las dos cosas: el caballo vuelve y tapa la diagonal hacia g7. }
11. Bg5 { [%hint Sumá otro atacante sobre la pieza que tapa la diagonal.] Ahora el caballo de f6 está atacado dos veces y solo lo defiende el peón de g7. }
```

Las negras suelen responder `11...c5` para echar a tu dama: tomá ese peón con `12.Qxc5`. Si el caballo vuelve a e4 atacando dama y alfil, la dama regresa a d4. Después seguí con Nc3 y las torres a la columna e: el rey negro todavía no tiene un lugar seguro.

## Variante: Defensa Comprometida (7...dxc3) {#comprometida} [club] [gambito]
Si las negras se comen otro peón con `7...dxc3`, quedan con dos peones de más pero muy atrasadas en el desarrollo. Es el escenario soñado del Evans.

```pgn
1. e4 e5 2. Nf3 Nc6 3. Bc4 Bc5 4. b4 { [%hint Ofrecé un peón del flanco de dama para ganar tiempos contra el alfil.] }
Bxb4 5. c3 { [%hint Echá al alfil y prepará el avance central.] }
Ba5 6. d4 { [%hint Golpeá el centro antes de que las negras se acomoden.] }
exd4 7. O-O { [%hint Sacá el rey de la diagonal del alfil de a5.] }
dxc3 { Otro peón más, y otra pieza negra que sigue sin salir. }
8. Qb3 { [%hint Atacá f7 con dos piezas a la vez.] La dama y el alfil apuntan a f7. [%cal Gb3f7 Gc4f7] }
Qf6 { La defensa más firme de f7. }
9. e5 { [%hint Ganá otro tiempo atacando a la dama.] }
Qg6 10. Nxc3 { Recuperás un peón y sumás otra pieza al ataque. }
Nge7 11. Ba3 { [%hint Desarrollá la última pieza menor con una idea contra el enroque negro.] El alfil presiona e7: si ese caballo se mueve, la diagonal hacia f8 queda abierta. }
O-O 12. Rad1 { [%hint Ocupá la columna por donde las negras necesitan mover un peón para desarrollarse.] La torre frena el avance del peón de d, que las negras necesitan para sacar el alfil de c8. }
```

Vas dos peones abajo, pero el alfil de c8 y la torre de a8 no juegan y tu peón de e5 encierra al flanco de rey negro. Buscá saltos de caballo a d5 o e4 y mantené ese peón: es el que sostiene tu ataque.

## Variante: Aceptado con 5...Be7 {#aceptado-be7} [club] [gambito]
Con `5...Be7` el alfil se retira a una casilla más segura y las negras buscan cambiar tu alfil de c4. Kasparov la usó con blancas para ganarle a Anand en Riga, 1995.

```pgn
1. e4 e5 2. Nf3 Nc6 3. Bc4 Bc5 4. b4 { [%hint Ofrecé un peón del flanco de dama para ganar tiempos contra el alfil.] }
Bxb4 5. c3 { [%hint Echá al alfil y prepará el avance central.] }
Be7 6. d4 { [%hint Golpeá el centro antes de que las negras se acomoden.] }
Na5 { Las negras atacan tu alfil de c4 para cambiarlo. }
7. Be2 { [%hint Conservá el alfil en una casilla segura.] El alfil vale más que el tiempo que perdés: lo vas a necesitar para el ataque. }
exd4 8. Qxd4 { [%hint Recuperá el centro con la pieza que además apunta al flanco de rey.] La dama recupera el peón y mira a g7. }
Nf6 9. e5 { Echás al caballo y ganás espacio. }
Nc6 10. Qh4 Nd5 11. Qg3 { [%hint Mantené la dama frente al enroque negro.] La dama apunta a g7 y obliga a las negras a pensar cada jugada del flanco de rey. }
g6 12. O-O Nb6 13. c4 { Le quitás la casilla d5 al caballo y ganás espacio. }
d6 14. Rd1 { [%hint Llevá una torre a la columna que se está por abrir.] }
Nd7 15. Bh6 { [%hint Atacá la casilla que dejó débil el peón de g6.] Desde h6 el alfil controla f8: el rey negro ya no puede enrocar corto. }
```

Las negras tienen un peón de más, pero su rey no tiene dónde esconderse. Seguí con Nc3 y las torres al centro, y abrí la posición con el cambio en d6 cuando te convenga.

## Variante: Gambito Evans rehusado {#rehusado} [básica]
Muchos jugadores no aceptan el peón y retiran el alfil a b6. No pasa nada: el peón de b4 te queda como una ganancia de espacio en el flanco de dama.

```pgn
1. e4 e5 2. Nf3 Nc6 3. Bc4 Bc5 4. b4 { [%hint Ofrecé un peón del flanco de dama para ganar tiempos contra el alfil.] }
Bb6 5. a4 { [%hint Usá el peón de a para molestar al alfil de b6.] Amenazás a5: el alfil se quedaría casi sin casillas. }
a6 { Le deja una retirada en a7. }
6. c3 { Sostenés el peón de b4 y preparás d4. }
Nf6 7. d3 { Un centro sólido: el avance d4 puede esperar al momento justo. }
d6 8. O-O O-O 9. Nbd2 { Desarrollo tranquilo, como en la Italiana lenta. }
```

Es una posición de maniobras parecida a la Italiana lenta, con un extra: tu peón de b4 te da espacio para jugar a5 más adelante. Seguí con Re1, h3 y el avance d4 cuando tengas todo listo.

Si las negras responden a `5.a4` con `5...a5`, empujá `6.b5`: después de `6...Nd4 7.Nxd4 Bxd4 8.c3` ganás tiempos contra el alfil.

## Trampa a favor: El doble ataque en d5 {#doble-ataque-d5} [básica]
Si las negras responden a `6.d4` con `6...Nf6` y después se comen el peón de e4, tu dama salta a d5 con dos amenazas a la vez.

```pgn
1. e4 e5 2. Nf3 Nc6 3. Bc4 Bc5 4. b4 { [%hint Ofrecé un peón del flanco de dama para ganar tiempos contra el alfil.] }
Bxb4 5. c3 { [%hint Echá al alfil y prepará el avance central.] }
Ba5 6. d4 { [%hint Golpeá el centro antes de que las negras se acomoden.] }
Nf6 { Natural, pero ya es un error: después del cambio en e5 el caballo de f6 queda atacado. }
7. dxe5 { [%hint Ganá espacio en el centro con ganancia de tiempo sobre el caballo.] }
Nxe4?? { Parece que recupera el peón, pero el caballo queda suelto. }
8. Qd5 { [%hint Buscá una casilla para la dama desde donde ataque dos cosas a la vez.] La dama amenaza mate en f7 y ataca el caballo de e4. Las negras pueden salvar una de las dos cosas, no las dos. [%cal Gd5f7 Gd5e4] }
Qe7 { Defiende f7, pero el caballo cae. }
9. Qxe4 { Ganaste una pieza. }
```

Si en vez de tomar en e4 el caballo va a g4, igual quedás claramente mejor: tu peón de e5 le quita casillas y vos desarrollás con tiempo. Y si después de `8.Qd5` el caballo se escapa a c3 o f2, es mate en f7.
