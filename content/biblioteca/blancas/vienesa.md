## Para empezar
Con `2.Nc3` defendés el peón de e4 y, sobre todo, dejás libre el peón de f para jugar f4. Es la idea del Gambito de Rey con una pieza ya desarrollada: si las negras golpean en el centro con ...d5, el caballo de c3 está ahí para pelear.

En esta ficha tenés dos planes:

- Contra `2...Nf6`, el Gambito Vienés: `3.f4` enseguida.
- Contra `2...Nc6`, primero `3.Bc4` y d3, y después f4 cuando el centro está firme.

## Ideas y planes
- **El avance f4.** Abre la columna f para tu torre y ataca el peón de e5. Si las negras cambian en f4, el centro queda para vos.
- **El peón de e5.** En el Gambito Vienés, después de `3...d5 4.fxe5`, tu peón de e5 le quita casillas al caballo negro y te da espacio en el flanco de rey.
- **El alfil de c4.** Contra `2...Nc6` apunta a f7. Con d3 lo sostenés y armás un centro sólido antes de abrir el juego.
- **La diagonal de tu dama.** Mientras el caballo de g1 no salga, tu dama mira g4 y h5: un caballo negro que se instala ahí sin defensa se pierde (ver las trampas).
- **Cuidado con tu rey.** Después de f4, la diagonal que va de g1 a a7 queda abierta. Antes de abrir más el juego, enrocá y mirá qué piezas negras apuntan por ahí.

## Consejos
- Contra `2...Bc5`, con `3.Nf3` desarrollás y atacás el peón de e5.
- En el Gambito Vienés, si las negras juegan `3...d6`, seguí con `4.Nf3` y un desarrollo normal.
- Contra `3...exf4 4.e5 Qe7`, defendé con `5.Qe2` y el caballo negro tiene que volver a g8.
- En la línea de `3.Bc4`, prepará f4 con d3: si avanzás antes, las negras se comen el peón de e4 con el caballo y quedan mejor.
- Antes de cada jugada, mirá si tu dama puede comerse algo en g4 o h5.

## Variante: Gambito Vienés con 3...d5 {#gambito-d5} [básica]
La respuesta más fuerte: las negras contragolpean en el centro. Tomás en e5 y peleás por la iniciativa.

```pgn
1. e4 e5 2. Nc3 { [%hint Desarrollá una pieza que defienda e4 y deje libre el peón de f.] La Vienesa: el caballo cuida e4 y el peón de f queda listo para avanzar. }
Nf6 3. f4 { [%hint Atacá el centro negro desde el flanco, como en el Gambito de Rey.] El Gambito Vienés. }
d5 { Contragolpe central: es la mejor respuesta. }
4. fxe5 { [%hint Ganá espacio y atacá al caballo de f6 al mismo tiempo.] }
Nxe4 5. Nf3 { [%hint Desarrollá el caballo y controlá d4.] }
Be7 6. d4 { [%hint Ocupá el centro con el peón de d.] }
O-O 7. Bd3 { [%hint Desarrollá el alfil apuntando al caballo de e4 y al enroque negro.] }
f5 { Las negras sostienen el caballo de e4. }
8. exf6 { Tomás al paso y abrís la columna f. }
Bxf6 9. O-O Nc6 10. Nxe4 { [%hint Cambiá el caballo fuerte de las negras.] }
dxe4 11. Bxe4 { Ganás un peón, pero mirá tu peón de d4: lo atacan tres piezas negras. }
```

Las negras recuperan el peón con `11...Nxd4`. Ahí no retomes con el caballo: mirá la trampa en contra "La recaptura en d4". Con `12.c3` se cambian damas y queda un final parejo.

## Variante: Gambito Vienés aceptado (3...exf4) {#gambito-aceptado} [club] [gambito]
Si las negras toman el peón, lo echás con e5 y lo recuperás más tarde con el alfil, con mejor desarrollo.

```pgn
1. e4 e5 2. Nc3 { [%hint Desarrollá una pieza que defienda e4 y deje libre el peón de f.] }
Nf6 3. f4 { [%hint Atacá el centro negro desde el flanco, como en el Gambito de Rey.] }
exf4 { Las negras aceptan el gambito. }
4. e5 { [%hint Echá al caballo con un peón.] }
Ng8 5. Nf3 { [%hint Desarrollá y quitale a la dama negra la casilla del jaque.] El caballo controla h4: así ...Qh4+ ya no molesta. }
d6 6. d4 { [%hint Ocupá el centro.] }
dxe5 7. Qe2 { [%hint Recuperá el peón con una pieza que además mire la columna del rey negro.] }
Be7 8. Qxe5 { Recuperás el peón: tu dama queda activa y el alfil de e7, clavado. }
Nc6 9. Bb5 { [%hint Clavá el caballo que ataca a tu dama.] }
Bd7 10. Bxc6 { Le dejás a las negras peones doblados en la columna c. }
bxc6 11. Bxf4 { [%hint Recuperá el peón del gambito con desarrollo.] Material parejo y mejor estructura para vos. }
```

Con el enroque largo y la dama atenta a c7, la presión sobre los peones negros del flanco de dama es tu plan.

## Variante: 2...Nc6 con 3.Bc4 {#bc4-bc5} [básica]
Contra `2...Nc6`, el alfil va a c4 y el centro se arma con d3. Recién después llega f4.

```pgn
1. e4 e5 2. Nc3 { [%hint Desarrollá una pieza que defienda e4 y deje libre el peón de f.] }
Nc6 3. Bc4 { [%hint Desarrollá el alfil apuntando a f7.] }
Nf6 4. d3 { [%hint Sostené el peón de e4 con un peón antes de abrir el juego.] }
Bc5 5. f4 { [%hint Con tu centro firme, atacá el centro negro desde el flanco, como en el Gambito de Rey.] }
d6 6. Nf3 { Desarrollás y presionás e5 dos veces. }
Bg4 { Clava tu caballo. }
7. Na4 { [%hint Antes de ocuparte de la clavada, atacá al alfil que apunta a tu rey.] El alfil de c5 es la mejor pieza negra: mira g1. }
Bb6 8. Nxb6 axb6 9. c3 { [%hint Quitale al caballo negro la casilla central.] Controlás d4 y le das aire a tu dama. }
```

Tenés la pareja de alfiles y un centro flexible. Enrocá corto y seguí con h3 para preguntarle al alfil de g4 qué quiere hacer.

## Variante: 2...Nc6 con 3.Bc4 Nf6 4.d3 Na5 {#bc4-na5} [club]
Las negras van a buscar tu alfil de c4 con el caballo. Lo dejás cambiar y usás el tiempo para desarrollarte.

```pgn
1. e4 e5 2. Nc3 { [%hint Desarrollá una pieza que defienda e4 y deje libre el peón de f.] }
Nc6 3. Bc4 { [%hint Desarrollá el alfil apuntando a f7.] }
Nf6 4. d3 { [%hint Sostené el peón de e4 con un peón antes de abrir el juego.] }
Na5 { Las negras van a cambiar tu alfil de c4. }
5. Nge2 { [%hint Desarrollá el caballo sin tapar el peón de f.] El caballo deja libre el peón de f para un futuro f4. }
Bc5 6. O-O Nxc4 7. dxc4 { Tus peones de c4 y e4 controlan d5. }
d6 8. Ng3 { [%hint Llevá el caballo hacia el flanco de rey, donde va a pelear.] }
Be6 9. Qd3 { Defendés el peón de c4 y conectás tus piezas. }
```

Con la dama en d3 y el caballo en g3 tenés el salto a f5 y, después de Kh1, la opción de f4 para abrir la columna de tu torre: mientras el rey esté en g1, el alfil de c5 clava el peón de f2.

## Trampa en contra: La recaptura en d4 {#recaptura-d4} [club]
En el Gambito Vienés con `3...d5`, las negras recuperan el peón con `11...Nxd4`. Retomar con el caballo parece obvio, pero abre la diagonal de tu rey.

```pgn
1. e4 e5 2. Nc3 { [%hint Desarrollá una pieza que defienda e4 y deje libre el peón de f.] }
Nf6 3. f4 { [%hint Atacá el centro negro desde el flanco, como en el Gambito de Rey.] }
d5 4. fxe5 { [%hint Ganá espacio y atacá al caballo de f6 al mismo tiempo.] }
Nxe4 5. Nf3 { [%hint Desarrollá el caballo y controlá d4.] }
Be7 6. d4 { [%hint Ocupá el centro con el peón de d.] }
O-O 7. Bd3 { [%hint Desarrollá el alfil apuntando al caballo de e4 y al enroque negro.] }
f5 8. exf6 Bxf6 9. O-O Nc6 10. Nxe4 { [%hint Cambiá el caballo fuerte de las negras.] }
dxe4 11. Bxe4 Nxd4 { Las negras recuperan el peón: el alfil de f6 y la dama apoyan al caballo. }
12. c3 { [%hint Antes de recapturar, mirá la diagonal que va de d4 a tu rey.] Atacás al caballo sin abrir la diagonal de tu rey. }
(12. Nxd4?? Qxd4+ { Jaque por la diagonal de tu rey. Y si cambiás damas, el alfil de f6 retoma con jaque y también perdés material. } 13. Kh1 Qxe4 { Las negras ganaron una pieza. })
Nxf3+ 13. Bxf3 Qxd1 14. Rxd1 { Final parejo, sin sustos. }
```

La regla para recordar: con f4 jugado y tu rey en g1, antes de capturar en d4 fijate qué piezas negras miran esa casilla.

## Trampa a favor: El caballo colgado en h5 {#caballo-en-h5} [básica]
En el Gambito Vienés aceptado, después de `4.e5` muchos jugadores llevan el caballo a h5 por costumbre del Gambito de Rey, donde en esa casilla está a salvo. En la Vienesa no lo está.

```pgn
1. e4 e5 2. Nc3 { [%hint Desarrollá una pieza que defienda e4 y deje libre el peón de f.] }
Nf6 3. f4 { [%hint Atacá el centro negro desde el flanco, como en el Gambito de Rey.] }
exf4 4. e5 { [%hint Echá al caballo con un peón.] }
Nh5?? { Parece sostener el peón de f4, pero el caballo queda en la diagonal de tu dama. }
5. Qxh5 { [%hint Mirá la diagonal de tu dama: con el caballo de g1 en casa, está abierta.] Ganaste un caballo. }
```

En el Gambito de Rey el caballo de f3 tapa esa diagonal; acá, con el caballo todavía en g1, la dama llega a h5 sin obstáculos.

## Trampa a favor: El caballo colgado en g4 {#caballo-en-g4} [básica]
En la línea de `3.Bc4`, después de `5.f4` las negras a veces saltan a g4 para atacar f2 con caballo y alfil. Pero tu dama ve esa casilla.

```pgn
1. e4 e5 2. Nc3 { [%hint Desarrollá una pieza que defienda e4 y deje libre el peón de f.] }
Nc6 3. Bc4 { [%hint Desarrollá el alfil apuntando a f7.] }
Nf6 4. d3 { [%hint Sostené el peón de e4 con un peón antes de abrir el juego.] }
Bc5 5. f4 { [%hint Con tu centro firme, atacá el centro negro desde el flanco, como en el Gambito de Rey.] }
Ng4?? { Busca atacar f2 con el caballo y el alfil, pero nadie defiende al caballo. }
6. Qxg4 { [%hint Mirá la diagonal de tu dama: con el caballo de g1 en casa, está abierta.] Ganaste un caballo. }
```

Es el mismo tema que la trampa anterior: mientras el caballo de g1 no salga, la diagonal de la dama hasta h5 está libre.
