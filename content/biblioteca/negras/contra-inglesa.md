## Para empezar
Con `1...e5` tomás tu parte del centro. Las blancas juegan una especie de Siciliana con un tiempo de más, pero tu desarrollo es simple: los caballos a f6 y c6, el alfil a b4 o e7, y el enroque.

- Contra los dos caballos blancos con g3, saltá con tu caballo a d4.
- Si las blancas fianchettan antes de sacar el caballo de g1, golpeá con d5: es un Dragón de la Siciliana visto desde el otro lado.
- Cuando el alfil de g2 y el caballo de c3 apuntan a tu caballo de d5, retiralo a b6: desde ahí sigue cuidando el centro.
- **Contra 1.Nf3** esta ficha no trae líneas. Lo más simple es `1...d5` y jugar como contra 1.d4: muchas veces las blancas terminan jugando d4 o c4 y la partida vuelve a terreno conocido.

## Ideas y planes
- **Cuatro Caballos con g3**: el salto `...Nd4` cambia el caballo de f3, y tu alfil va a b4. Si las blancas cambian en d4, tu peón llega a d4 y les quita las casillas c3 y e3.
- **El cambio en c3**: tu alfil de b4 se cambia por el caballo cuando eso le dobla los peones a las blancas y te deja jugar `...d5`.
- **Dragón invertido**: después de `...d5` y `cxd5 Nxd5`, las blancas presionan con el alfil de g2 y con el avance b4-b5. Vos jugás `...Be6`, enrocás y llevás el caballo a d4 cuando lo echen de c6. La ruptura `...f5` te da juego en el flanco de rey.
- **Tu peón de e5** controla d4 y frena el centro blanco. Si queda flojo, sostenelo con `...f6` o con una torre en e8.

## Consejos
- Si las blancas comen tu peón de e5 con el caballo, no te apures a defender nada: con la dama en e7 lo atacás y quedás mejor (y quizás ganás algo más, mirá la trampa).
- En el Dragón invertido, cuando el peón blanco llegue a b5 contra tu caballo de c6, llevalo a d4.
- Antes de jugar `...f5`, fijate que tu rey no quede expuesto en la diagonal que va a g8.
- Contra los Cuatro Caballos con `4.e3` o `4.d3`, lo más simple es `4...Bb4`: desarrollás y presionás el caballo de c3.
- Contra 1.Nf3, jugá 1...d5 y desarrollate como contra 1.d4.

## Variante: Cuatro Caballos con 4.g3 {#cuatro-caballos-g3} [básica]
El esquema más popular de las blancas: los dos caballos y el alfil a g2. El salto a d4 te simplifica el juego.

```pgn
1. c4 e5 2. Nc3 Nf6 3. Nf3 Nc6 4. g3 Nd4 { [%hint Ocupá con el caballo una casilla central y ofrecé el cambio del caballo de f3.] }
5. Bg2 Nxf3+ 6. Bxf3 Bb4 { [%hint Desarrollá el alfil presionando el caballo de c3.] }
7. O-O O-O 8. d3 h6 { [%hint Evitá que el alfil de c1 te clave el caballo.] }
9. Bg2 c6 { [%hint Prepará el avance central del peón de d.] }
10. a3 Bxc3 { Cambiás el alfil atacado y les doblás los peones a las blancas. }
11. bxc3 d5 12. cxd5 cxd5
```

Tenés un centro sólido con peones en d5 y e5; las blancas se quedan con el par de alfiles y la columna b. Seguí con `...Qc7` o `...Be6` y la torre a la columna c, y vigilá el peón de b7, que la torre o la dama blanca van a atacar por la columna b.

## Variante: Cuatro Caballos con 5.Nxd4 {#cambio-en-d4} [club]
Si las blancas cambian enseguida los caballos, tu peón llega a d4 y ataca al caballo de c3.

```pgn
1. c4 e5 2. Nc3 Nf6 3. Nf3 Nc6 4. g3 Nd4 { [%hint Ocupá con el caballo una casilla central y ofrecé el cambio del caballo de f3.] }
5. Nxd4 exd4 6. Nd5 Nxd5 { Cambiás el caballo que se instaló en el centro. }
7. cxd5 Be7 8. Bg2 O-O 9. O-O c6 { [%hint Atacá el peón de d5 antes de que las blancas lo sostengan.] }
```

Seguí con `...Bf6` para sostener tu peón de d4 y la dama a c7. Ese peón le quita casillas a las blancas, que van a buscar e3 para cambiarlo.

## Variante: Dragón invertido (3.g3) {#dragon-invertido} [básica]
Con `3.g3` las blancas fianchettan antes de sacar el caballo de g1. Contestás en el centro con d5: es una Siciliana Dragón con los colores cambiados.

```pgn
1. c4 e5 2. Nc3 Nf6 3. g3 d5 { [%hint Ocupá el centro con un golpe de peón.] }
4. cxd5 Nxd5 5. Bg2 Nb6 { [%hint Retirá el caballo, que ya tiene dos atacantes, a una casilla segura.] }
6. Nf3 Nc6 7. O-O Be7 8. d3 O-O 9. a3 Be6 { [%hint Desarrollá el alfil donde cuide d5 y c4.] }
10. b4 a5 { [%hint Frená el avance de los peones blancos atacando el de b4.] }
11. b5 Nd4 { [%hint Llevá el caballo atacado a la casilla central más fuerte.] }
```

El caballo de d4 es tu mejor pieza. Las blancas suelen seguir con `Bb2`, `Be3` o `Nd2`; vos reforzás e5 con `...f6` o abrís la columna c con `...c6`.

## Variante: Fianchetto con 2.g3 {#2g3} [club]
El mismo esquema en otro orden: el alfil va a g2 antes que los caballos. Contestás igual y llegás a la posición del Dragón invertido.

```pgn
1. c4 e5 2. g3 Nf6 3. Bg2 d5 { [%hint Ocupá el centro con un golpe de peón.] }
4. cxd5 Nxd5 5. Nc3 Nb6 { [%hint Retirá el caballo, que ya tiene dos atacantes, a una casilla segura.] }
6. Nf3 Nc6 7. O-O Be7 8. d3 O-O 9. Be3 Be6 { [%hint Desarrollá el alfil donde cuide d5 y c4.] }
10. Rc1 f5 { [%hint Ganá espacio en el flanco de rey, como hacen las blancas en el Dragón.] }
```

Con `...f5` tus peones del flanco de rey avanzan como en el ataque contra el Dragón, pero del otro lado. Seguí con `...Kh8`, que saca al rey de la diagonal hacia g8, y con `...Bf6` o `...Qd7`.

## Trampa a favor: Mate del caballo en f3 {#mate-en-f3} [básica]
Contra el salto a d4, el codicioso `5.Nxe5` ya es un error. Si además las blancas retiran el caballo a d3, el tuyo da mate en f3.

```pgn
1. c4 e5 2. Nc3 Nf6 3. Nf3 Nc6 4. g3 Nd4 { [%hint Ocupá con el caballo una casilla central y ofrecé el cambio del caballo de f3.] }
5. Nxe5 { Se lleva un peón, pero el caballo deja libre f3 y queda en la columna de tu dama. } Qe7 { [%hint Atacá el caballo y ponete en la misma columna que el rey blanco.] }
6. Nd3?? { Retira el caballo, pero deja la columna e abierta hasta el rey. } Nf3# { El peón de e2 no puede comer porque está clavado por tu dama, y el de g ya no está en g2. }
```

Mate en seis jugadas. Aunque las blancas no caigan en `6.Nd3??`, después de `5...Qe7` quedás mejor: si sostienen el caballo con `6.f4`, `6...d6` lo echa igual y el rey blanco queda expuesto en la columna e.
