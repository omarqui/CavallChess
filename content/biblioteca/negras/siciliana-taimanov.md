## Para empezar
Con `2...e6` y `4...Nc6` presionás enseguida al caballo de d4. A diferencia de otras Sicilianas, tu peón de d puede quedarse un buen rato en d7: más adelante decidís si va a d6 o si rompe con `...d5`.

Tu esquema tiene tres piezas clave: la dama en c7, que vigila e5 y la columna c; el peón en a6, que le quita b5 a los caballos blancos; y el caballo de g8, que sale a f6 o a e7 según lo que hagan las blancas.

- Jugá `...a6` pronto: sin ese peón, un caballo blanco en b5 ataca a tu dama de c7 y amenaza saltar a d6.
- La dama en c7 controla e5: con ella ahí, el avance blanco e5 cuesta mucho.
- Desarrollá las piezas antes de mover más peones; el alfil de f8 sale a b4, c5 o e7 según la posición.
- Si las blancas no protegen el peón de e4, mirá si podés tomarlo.

## Ideas y planes
- **Contra el Ataque Inglés (`Be3`, `Qd2` y enroque largo):** clavás el caballo de c3 con `...Bb4`, saltás con `...Ne5` hacia c4 para cambiar el alfil de casillas claras y avanzás `...b5`. La columna b, que se abre cuando recapturás con el peón, apunta directo al rey blanco.
- **Contra `Bd3` y el enroque corto:** el caballo va a e5 y el alfil a c5, en la diagonal que termina en el rey blanco. Si las blancas empujan f4, el caballo salta a g6 y presiona ese peón.
- **Contra `6.Be2`:** acá no hay clavada (la dama blanca sigue en d1), pero `...Bb4` ataca al caballo de c3, que es el que defiende e4: amenazás `...Bxc3` y después `...Nxe4`. Si el caballo blanco se va al borde y cambia tu alfil de c8, quedás con un centro sólido y la columna b.
- **Contra `6.Ndb5`:** tu orden de jugadas lo permite, pero no es peligroso. La dama va a b8, `...a6` echa al caballo y, cuando vuelve a d4, tu dama regresa a c7.
- **Contra `5.Nb5`:** `...d6` le quita la casilla d6 al caballo. Si las blancas arman la estructura Maroczy (peones en c4 y e4), jugás el "erizo": piezas detrás de los peones (`...Be7`, `...b6`, `...Bb7`) y, cuando todo está listo, las rupturas `...b5` o `...d5`.

## Consejos
- `...Nxe4` solo funciona si tu alfil de b4 clava de verdad al caballo de c3, es decir, si detrás está la dama blanca en d2 o el rey en e1, y las blancas no jugaron f3. Si detrás del caballo no hay nada, como con la dama en d1 y el rey enrocado, el caballo defiende e4: primero tenés que cambiar en c3.
- Cuando tu dama está en c7, mirá si un caballo blanco puede llegar a b5 o d5 con tempo.
- Contra `5.Nb5`, no te apures a sacar el caballo de g8: primero `...d6`.
- En el erizo no hay apuro: las rupturas `...b5` y `...d5` funcionan cuando tus piezas ya están en su lugar.
- Si el caballo blanco se va a a4 o a3, preguntate cómo va a volver al juego y no lo dejes regresar fácil.

## Variante: Ataque Inglés {#ataque-ingles} [club]
Con `6.Be3`, `7.Qd2` y el enroque largo, las blancas buscan un ataque directo. Vos clavás el caballo, llevás el tuyo a c4 y abrís la columna b.

```pgn
1. e4 c5 2. Nf3 e6 3. d4 cxd4 4. Nxd4 Nc6 5. Nc3 Qc7 { [%hint Ubicá la dama donde vigile e5 y la columna c.] }
6. Be3 a6 { [%hint Quitale al caballo blanco la casilla b5 antes de seguir desarrollando.] }
7. Qd2 Nf6 8. O-O-O Bb4 { [%hint Clavá el caballo que defiende el peón de e4.] }
9. f3 { Ahora el peón de e4 está protegido de verdad. } Ne5 { [%hint Saltá con el caballo hacia la casilla desde donde ataca a la dama y al alfil.] }
10. Nb3 b5 { Ganás espacio y apoyás el salto a c4. }
11. Kb1 Nc4 12. Bxc4 bxc4 { Las blancas cambiaron su alfil de casillas claras y se abrió la columna b. }
13. Nc1 Rb8 { [%hint Llevá la torre a la columna abierta, frente al rey blanco.] }
```

La columna b y el peón de c4 te dan presión sobre el flanco de dama blanco. Enrocá corto y, según lo que hagan las blancas, preparás `...d5` o doblás piezas en la columna b.

## Variante: Sistema con 7.Bd3 {#bd3} [básica]
Con `7.Bd3` y el enroque corto, las blancas eligen un esquema sencillo. Tu caballo va a e5 y tu alfil apunta al rey blanco desde c5.

```pgn
1. e4 c5 2. Nf3 e6 3. d4 cxd4 4. Nxd4 Nc6 5. Nc3 Qc7 { [%hint Ubicá la dama donde vigile e5 y la columna c.] }
6. Be3 a6 { [%hint Quitale al caballo blanco la casilla b5 antes de seguir desarrollando.] }
7. Bd3 Nf6 8. O-O Ne5 { [%hint Saltá al centro con el caballo, apuntando al alfil de d3.] }
9. h3 { Quita la casilla g4. } Bc5 { [%hint Apuntá con el alfil a la diagonal que termina en el rey blanco.] }
10. Kh1 { El rey sale de esa diagonal. } d6 { El peón defiende al caballo de e5 y al alfil de c5. }
11. f4 Ng6 { [%hint Retirá el caballo atacado a una casilla desde donde presione al peón que avanzó.] }
```

Si las blancas siguen con `12.f5`, el caballo vuelve a e5, su mejor casilla. Enrocá corto y buscá `...b5` y `...Bb7` para presionar el peón de e4.

## Variante: Variante con 6.Be2 {#be2} [club]
Con `6.Be2` las blancas enrocan corto y juegan con calma. `...Bb4` presiona e4, porque amenaza `...Bxc3` y `...Nxe4`; si el caballo blanco se va al borde, quedás con un centro sólido.

```pgn
1. e4 c5 2. Nf3 e6 3. d4 cxd4 4. Nxd4 Nc6 5. Nc3 Qc7 { [%hint Ubicá la dama donde vigile e5 y la columna c.] }
6. Be2 a6 { [%hint Quitale al caballo blanco la casilla b5 antes de seguir desarrollando.] }
7. O-O Nf6 8. Be3 Bb4 { [%hint Atacá el caballo que defiende el peón central.] }
9. Na4 { El caballo esquiva el ataque y amenaza saltar a b6. } Be7 { [%hint Volvé con el alfil antes de que un peón blanco lo eche con ganancia de tiempo.] Si no, c3 lo echaba. }
10. Nxc6 bxc6 { Recapturás hacia el centro. }
11. Nb6 Rb8 12. Nxc8 Qxc8 { Las blancas tienen la pareja de alfiles, pero vos tenés un centro sólido y la columna b. }
```

Seguí con `...O-O`, `...d6` y `...Qc7`. Si el alfil blanco va a d4, `...c5` lo echa y suma control sobre el centro.

## Variante: Variante con 6.Ndb5 {#ndb5} [club]
Como jugás `...Qc7` antes de `...a6`, el caballo de d4 puede saltar a b5 y atacar a tu dama. No es peligroso si sabés la respuesta: la dama va a b8, echás al caballo con `...a6` y, cuando vuelve a d4, tu dama regresa a c7.

```pgn
1. e4 c5 2. Nf3 e6 3. d4 cxd4 4. Nxd4 Nc6 5. Nc3 Qc7 { [%hint Ubicá la dama donde vigile e5 y la columna c.] }
6. Ndb5 { Ataca a tu dama y amenaza entrar en c7 o en d6. } Qb8 { [%hint Retirá la dama a una casilla desde donde siga vigilando d6 y e5.] Es la retirada más segura. }
7. Be3 a6 { [%hint Echá al caballo que se metió en tu campo.] }
8. Nd4 Nf6 9. Be2 Qc7 { [%hint Con el caballo de vuelta en d4, devolvé la dama a su mejor casilla.] }
10. O-O Bb4 { [%hint Atacá el caballo que defiende el peón central.] Llegaste a la misma posición de la variante con 6.Be2. }
```

Desde acá seguís como en la variante con `6.Be2`. Si en la jugada 8 las blancas prueban `8.Bb6`, con la amenaza `Nc7+`, no te asustes: `8...axb5 9.Nxb5 Bb4+ 10.c3 Ba5!` te da buen juego, y si `11.Nd6+`, el rey va a f8. Tiene que ser `10...Ba5`: el alfil cubre c7 y ataca al de b6, mientras que las otras jugadas dejan entrar `Nc7+` y perdés la torre de a8.

## Variante: 5.Nb5 y la estructura Maroczy {#nb5} [básica]
Con `5.Nb5` el caballo amenaza saltar a d6. Lo frenás con `...d6`, y si las blancas arman el centro con c4, jugás el erizo.

```pgn
1. e4 c5 2. Nf3 e6 3. d4 cxd4 4. Nxd4 Nc6 5. Nb5 d6 { [%hint Quitale al caballo la casilla de entrada en tu campo.] }
6. c4 Nf6 7. N1c3 a6 8. Na3 { El caballo de a3 quedó en el borde: su camino de vuelta es por c2. } Be7
9. Be2 O-O 10. O-O b6 { [%hint Prepará la salida de tu alfil de casillas claras hacia la diagonal larga.] }
11. Be3 Bb7 { El alfil presiona e4. }
12. f3 Rc8 { [%hint Llevá una torre frente al peón de c4.] }
```

Es una posición de maniobras: tus piezas esperan detrás de los peones el momento de romper con `...b5` o `...d5`. Mientras tanto, `...Ne5` y `...Qc7` son jugadas útiles.

## Trampa a favor: El caballo clavado de c3 {#peon-e4} [club]
En el Ataque Inglés, la jugada `9.f3` no es un detalle: con tu alfil en b4, el caballo de c3 está clavado contra la dama de d2 y no defiende de verdad el peón de e4.

```pgn
1. e4 c5 2. Nf3 e6 3. d4 cxd4 4. Nxd4 Nc6 5. Nc3 Qc7 { [%hint Ubicá la dama donde vigile e5 y la columna c.] }
6. Be3 a6 { [%hint Quitale al caballo blanco la casilla b5 antes de seguir desarrollando.] }
7. Qd2 Nf6 8. O-O-O Bb4 { [%hint Clavá el caballo que defiende el peón de e4.] }
9. a3?? { Le pregunta al alfil, pero se olvida del peón de e4. } Nxe4 { [%hint Tomá el peón que el caballo clavado no puede defender.] Si 10.axb4, 10...Nxd2 se lleva la dama. }
```

Si las blancas salvan la dama con `10.Qe1`, seguí con `10...Nxc3`: el caballo ataca a la torre de d1 y, después de los cambios, terminás con material de ventaja.
