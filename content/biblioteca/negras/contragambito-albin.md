## Para empezar
Contra `2.c4` no te quedás defendiendo d5: contraatacás con `2...e5`. Después de `3.dxe5 d4` tu peón se instala en d4, le quita las casillas c3 y e3 al caballo y al peón blancos, y vos sacás las piezas rápido. Tenés un peón menos, pero el de e5 quedó lejos de su base y muchas veces lo recuperás.

- Empujá el peón a d4 enseguida: es el corazón de la apertura.
- El caballo de b8 va a c6, desde donde cuida d4 y mira a e5.
- Si las blancas atacan tu peón con e3 antes de tiempo, aparece el jaque en b4 y, con suerte, la Trampa de Lasker.
- Primero el desarrollo y después el peón: si lo recuperás con las piezas bien ubicadas, la apertura cumplió.

## Ideas y planes
- **El peón de d4** es tu mejor pieza: corta el centro blanco en dos. Cuidalo con `...Nc6` y, cuando haga falta, con un alfil en c5.
- **Recuperar e5**: contra `5.g3`, `5.Nbd2` y `5.a3`, el caballo de g8 viaja por e7 a g6 y se suma al de c6 para atacar e5. Cuando cae ese peón, el material vuelve a estar parejo y tus piezas quedan activas.
- **Contra `4.e3`**: el jaque `...Bb4+` obliga a tapar con el alfil; después cambiás en e3 y, si las blancas recapturan con el peón de f, la dama sale a h4 con jaque y recupera el peón.
- **El riesgo**: el Albin tiene fama de dudoso. Si las blancas sostienen e5 y terminan el desarrollo, te quedás con un peón menos sin compensación. Jugalo con actividad y sin perder tiempos.

## Consejos
- Antes de cada jugada preguntate si tu peón de d4 sigue bien defendido.
- Contra `4.e3` no dudes: primero el jaque en b4, después el cambio en e3.
- Contra `4.e4` no tomes al paso: después del cambio de damas las blancas quedan mejor desarrolladas. Seguí con `4...Nc6` como siempre.
- Si un caballo blanco se come tu peón de d4, no te desanimes: contá cuántas piezas atacan e5 y recuperalo.

## Variante: Fianchetto: 5.g3 {#fianchetto} [básica] [gambito]
La línea más jugada. Las blancas desarrollan el alfil en g2 y sostienen e5 con piezas; vos traés el caballo de g8 hasta g6 para ganarlo de vuelta.

```pgn
1. d4 d5 2. c4 e5 3. dxe5 d4 { [%hint Avanzá el peón que está atacado y clavá una cuña en el centro.] El peón de d4 le quita casillas al caballo de b1 y al peón de e2. }
4. Nf3 Nc6 { [%hint Defendé tu avanzada y sumá presión sobre el peón de e5.] }
5. g3 Nge7 { [%hint Empezá un viaje de caballo que termine atacando e5.] }
6. Bg2 Ng6 7. O-O Ngxe5 { Recuperaste el peón: el material está igualado. }
8. Nxe5 Nxe5 9. b3 Bc5 { [%hint Desarrollá el alfil donde además proteja tu avanzada.] }
10. Bb2 O-O 11. Nd2 a5
```

Posición pareja, con tu peón de d4 todavía firme. El alfil de b2 y el de g2 apuntan a tu avanzada y a b7: cuidalos. Seguí con `...Re8` y `...a4` para molestar en el flanco de dama. Si un caballo blanco va a e4 a atacar tu alfil, retiralo a a7: desde ahí sigue cuidando d4.

## Variante: Con 5.Nbd2 {#nbd2} [club] [gambito]
El caballo de b1 va a b3 para atacar tu peón de d4. Lo dejás caer: a cambio recuperás e5 y tus piezas salen con tiempo.

```pgn
1. d4 d5 2. c4 e5 3. dxe5 d4 4. Nf3 Nc6 5. Nbd2 Nge7 { [%hint Empezá un viaje de caballo que termine atacando e5.] }
6. Nb3 Ng6 7. Nbxd4 { Las blancas ganaron tu avanzada. } Ngxe5 { [%hint Recuperá un peón y ofrecé el cambio de caballos.] }
8. Nxe5 Nxe5 9. e3 Bc5 { [%hint Desarrollá con ataque al caballo del centro.] }
```

Quedaste con un peón menos, pero con el desarrollo más rápido y el enroque a mano. Las ideas son `...O-O`, `...Bg4` para molestar a la dama y `...Qf6`: no le des tiempo a las blancas para terminar de ordenarse.

## Variante: Con 5.a3 {#a3} [club] [gambito]
Con a3 y b4 las blancas evitan el jaque en b4 y ganan espacio en el flanco de dama. El caballo de g8 hace el mismo viaje de siempre.

```pgn
1. d4 d5 2. c4 e5 3. dxe5 d4 4. Nf3 Nc6 5. a3 Nge7 { [%hint Empezá un viaje de caballo que termine atacando e5.] }
6. b4 Ng6 7. Bb2 a5 { [%hint Atacá el peón de avanzada antes de que te eche al caballo.] }
8. b5 Ncxe5 { [%hint Usá el caballo que te acaban de atacar para recuperar el peón.] }
9. Nxe5 Nxe5 10. e3 Bc5 { [%hint Sumá una pieza a la defensa de tu avanzada.] }
```

El material está igualado y tu peón de d4 está defendido. Si las blancas lo ganan, no te apures a recuperarlo: tus piezas son más activas, y `...Bg4`, el enroque y las torres al centro te dan juego.

## Variante: Contra 4.e3 {#e3} [básica] [gambito]
Atacar tu peón con e3 parece lo más lógico, pero te deja dar un jaque molesto. Esta es la forma de jugar cuando las blancas no caen en la trampa.

```pgn
1. d4 d5 2. c4 e5 3. dxe5 d4 4. e3 Bb4+ { [%hint Antes de cambiar peones, obligá a las blancas a tapar un jaque.] }
5. Bd2 dxe3 { [%hint Cambiá tu peón atacado por el que lo atacaba.] }
6. fxe3 { La buena: las blancas recapturan con el peón y no con el alfil. } Qh4+ { [%hint Aprovechá que el peón de f se fue y el rey blanco quedó expuesto.] }
7. g3 Qe4 { [%hint Atacá a la vez la torre y el peón que quedó suelto.] }
8. Nf3 Bxd2+ 9. Nbxd2 Qxe3+ 10. Qe2 Qxe2+ 11. Bxe2 Nc6 { Ahora el peón débil es el de e5. }
```

Recuperaste el peón y llegaste a un final cómodo: el peón de e5 está aislado y tu caballo ya lo ataca. Seguí con `...Nge7` y `...Ng6` para sumar otro atacante, y enrocá.

## Trampa a favor: Trampa de Lasker {#lasker} [básica]
Si contra el jaque en b4 las blancas toman tu alfil en lugar de recapturar en e3, tu peón avanza con jaque hasta la primera fila y se corona... en caballo.

```pgn
1. d4 d5 2. c4 e5 3. dxe5 d4 4. e3 Bb4+ 5. Bd2 dxe3
6. Bxb4?? { Se queda con el alfil, pero deja avanzar tu peón con jaque. } exf2+ { [%hint Seguí avanzando el peón con jaque.] }
7. Ke2 fxg1=N+ { [%hint Coroná, pero elegí la pieza que da jaque.] Si coronás dama no hay jaque y las blancas ganan un tiempo para defenderse. }
8. Ke1 { Si `8.Rxg1`, `8...Bg4+` ataca al rey y, detrás, a la dama de d1. } Qh4+ { [%hint Seguí con jaques: el rey blanco no tiene refugio.] }
9. Kd2 Nc6 { [%hint Traé otra pieza al ataque.] } 10. Bc3 Bg4
```

El rey blanco quedó en el centro, rodeado por tus piezas, y además tenés una pieza de más. Sigue el enroque largo con jaque y el ataque es decisivo.
