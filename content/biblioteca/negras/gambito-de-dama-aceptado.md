## Para empezar
Con `2...dxc4` aceptás el peón, pero **no tratás de quedártelo**: las blancas lo recuperan casi siempre con el alfil. Lo que ganás es tiempo. Mientras el alfil blanco va a c4, vos sacás el caballo, liberás tu alfil de f8 con e6 y atacás el centro con c5, o con e5 si las blancas jugaron e4.

- No defiendas el peón de c4 con b5: es la trampa clásica de esta apertura.
- Contra `3.Nf3` y `3.e3` el esquema es siempre el mismo: Nf6, e6, c5 y a6.
- Contra `3.e4`, respondé en el centro con e5.
- Enrocá corto y buscá cambiar el peón blanco de d4.

## Ideas y planes
- **El golpe c5** ataca d4. Si las blancas cambian en c5, las damas suelen salir del tablero y llegás a un final parejo. Si mantienen la tensión, muchas veces cambiás en d4 y les dejás un **peón aislado**.
- **Contra el peón aislado**: bloquealo con un caballo en d5, cambiá piezas menores y presionalo con las torres. Cuantas menos piezas quedan, más se nota su debilidad; con muchas piezas, en cambio, le da a las blancas casillas y juego de ataque.
- **`...a6` y `...b5`** ganan espacio en el flanco de dama, echan al alfil de c4 y le abren a tu alfil de c8 la diagonal larga desde b7.
- **Contra `3.e4`**: tu peón de e5 cambia el de d4 y el alfil va a e6 a ofrecer el cambio del alfil de c4. Aceptás un peón doblado en e6 a cambio de la columna f abierta y de un peón tuyo en d4 que molesta.
- **Otras jugadas blancas**: contra `3.Nf3 Nf6 4.Nc3`, `4...a6` prepara b5, y si `5.e4`, seguí con `5...b5`. Contra `4.Qa4+`, tapá con `4...c6` y, después de `5.Qxc4`, sacá el alfil a f5. En la Variante Central, si `4.d5`, `4...Nf6` ataca e4; si `4.dxe5`, después de `4...Qxd1+ 5.Kxd1 Nc6` el rey blanco perdió el enroque y tu caballo ataca e5.

## Consejos
- Jugá `...a6` antes de `...b5`: así el peón de b5 queda defendido.
- Si el alfil blanco apunta a e6 o f7 desde b3 o c4, revisá esos puntos antes de mover las piezas que los defienden.
- En el final sin damas no hay apuro: terminá el desarrollo y llevá una torre a la columna d o c antes que tu rival.
- Contra el peón aislado, el caballo en d5 es tu mejor pieza: no lo cambies sin motivo.

## Variante: Clásica con cambio de damas {#clasica-cambio} [básica]
La manera más simple de jugar de las blancas: cambian en c5 y las damas salen del tablero. Llegás a un final cómodo y sin riesgos.

```pgn
1. d4 d5 2. c4 dxc4 3. Nf3 Nf6 4. e3 e6 { [%hint Abrí la diagonal de tu alfil de casillas oscuras.] }
5. Bxc4 c5 { [%hint Golpeá el centro blanco con un peón de flanco.] }
6. O-O a6 { [%hint Prepará la expansión en el flanco de dama y quitale una casilla al alfil.] }
7. dxc5 Qxd1 8. Rxd1 Bxc5 9. Be2 O-O 10. Nbd2 Nc6 11. Nb3 Be7
```

Posición pareja y sin debilidades. Seguí con `...Bd7` y `...Rfc8` o `...Rfd8`, y disputá las columnas abiertas: el que las controla primero juega más cómodo.

## Variante: Clásica con 7.a4 {#clasica-a4} [club]
Con a4 las blancas frenan tu b5. Vos cambiás en d4 y jugás contra el peón aislado.

```pgn
1. d4 d5 2. c4 dxc4 3. Nf3 Nf6 4. e3 e6 { [%hint Abrí la diagonal de tu alfil de casillas oscuras.] }
5. Bxc4 c5 { [%hint Golpeá el centro blanco con un peón de flanco.] }
6. O-O a6 { [%hint Prepará la expansión en el flanco de dama y quitale una casilla al alfil.] }
7. a4 Nc6 { [%hint Desarrollá sumando presión sobre d4.] }
8. Qe2 cxd4 { [%hint Cambiá en el centro para dejarle a las blancas un peón aislado.] }
9. Rd1 Be7 10. exd4 O-O 11. Nc3 Nd5 { [%hint Bloqueá el peón aislado con una pieza que ningún peón pueda echar.] }
12. Bd3 Ncb4 { [%hint Atacá el alfil que apunta a tu enroque.] } 13. Bb1 Bd7
```

El peón de d4 está aislado y tu caballo de d5 lo bloquea. Seguí con `...Bc6` y `...Rc8`, y buscá cambiar piezas menores: cuanto más simplificada esté la posición, más se nota la debilidad del peón aislado.

## Variante: Variante Central (3.e4) {#central} [club]
Las blancas ocupan el centro con dos peones. La respuesta más directa es atacarlo enseguida.

```pgn
1. d4 d5 2. c4 dxc4 3. e4 e5 { [%hint Atacá el centro blanco antes de que se afiance.] }
4. Nf3 exd4 5. Bxc4 Nc6 { [%hint Defendé con desarrollo el peón que tenés de más.] }
6. O-O Be6 { [%hint Ofrecé el cambio de la pieza blanca más peligrosa.] }
7. Bxe6 fxe6 8. Qb3 Qd7 { [%hint Defendé e6; si la dama blanca se va a comer b7, se aleja del centro.] }
9. Qxb7 Rb8 10. Qa6 Nf6 11. Nbd2 Bd6
```

El material está igualado. A cambio del peón doblado tenés la columna f para las torres, la columna b para presionar y tu peón de d4, que le quita casillas a las blancas. Seguí con `...O-O` y `...e5` para sostenerlo.

## Variante: Con 3.e3 {#con-e3} [club]
Con `3.e3` las blancas preparan recuperar el peón con el alfil. Usás el mismo esquema que contra `3.Nf3` y llegás a la misma posición de la Clásica.

```pgn
1. d4 d5 2. c4 dxc4 3. e3 Nf6 { [%hint Desarrollá una pieza antes de pensar en el peón de c4.] }
4. Bxc4 e6 { [%hint Abrí la diagonal de tu alfil de casillas oscuras.] }
5. Nf3 c5 { [%hint Golpeá el centro blanco con un peón de flanco.] }
6. O-O a6 { [%hint Prepará la expansión en el flanco de dama y quitale una casilla al alfil.] }
7. Qe2 b5 { [%hint Ganá espacio con tiempo sobre el alfil.] }
8. Bb3 Bb7 { [%hint Ubicá el alfil en la diagonal larga.] }
9. Rd1 Nbd7 10. Nc3 Qc7 { [%hint Defendé el peón de c5 y conectá tus piezas antes de que se abra el centro.] }
11. e4 cxd4 12. Nxd4 Bc5 13. Be3 O-O
```

Las blancas abrieron el centro, pero tu desarrollo está completo y los alfiles apuntan bien. Seguí con `...Rfd8` o `...Rac8` y estate atento a la ruptura e5 y a los sacrificios en e6: con el alfil en b3 y un caballo en d4, las blancas siempre tienen esa idea.

## Trampa en contra: Defender el peón con b5 {#peon-con-b5} [básica]
La tentación de todo principiante es quedarse con el peón de c4 empujando b5. Con a4 y la dama a f3, las blancas te desarman el flanco de dama.

```pgn
1. d4 d5 2. c4 dxc4 3. e3 Nf6 { [%hint Desarrollá una pieza antes de pensar en el peón de c4.] }
(3... b5? { Parece sostener el peón, pero después del cambio en b5 la diagonal hasta a8 queda abierta. } 4. a4 c6 5. axb5 cxb5 6. Qf3 { La dama ataca la torre de a8 y no hay buena forma de taparla: vas a perder una pieza. })
4. Bxc4 e6 5. Nf3 c5
```

Con `3...Nf6` el peón de c4 se pierde igual, pero vos ganás tiempo y llegás a las posiciones de la Clásica.
