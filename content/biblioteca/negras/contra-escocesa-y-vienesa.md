## Para empezar
Después de `1.e4 e5` hay dos aperturas blancas que se salen del camino de siempre. En las dos, tu respuesta es activa:

- **Escocesa** (`2.Nf3 Nc6 3.d4`): cambiás en `d4` y, cuando el caballo blanco recaptura, sacás el alfil a `c5` atacándolo. La dama en `f6` suma presión sobre `f2` y `d4`.
- **Vienesa** (`2.Nc3`): sacás el caballo a `f6`. Si las blancas juegan el gambito `3.f4`, contestás en el centro con `3...d5`; si sacan el alfil a `c4`, desarrollás con `...Nc6` y `...Bc5`.
- En la Escocesa y en la Vienesa con `3.Bc4`, el punto `f2` es un buen objetivo para tu alfil de `c5`.
- No te olvides de enrocar: en estas aperturas el centro se abre rápido.

## Ideas y planes
- **Escocesa con `5.Nxc6`**: con `...Qf6` amenazás mate en `f2` y recién después recapturás con el peón de `d`, que les abre camino a tus alfiles. Tu ventaja de desarrollo te deja enrocar largo con comodidad, y si después se cambian las damas, el final es parejo.
- **Escocesa con `5.Be3`**: las blancas defienden el caballo de `d4`. Vos sumás presión con `...Qf6` y `...Nge7`, enrocás y retirás el alfil a `b6` para cambiarlo en buenas condiciones.
- **Gambito Vienés (`3.f4`)**: no tomes el peón. `3...d5` abre el centro y tu caballo se instala en `e4`; después, `...f5` sostiene al caballo y abre la columna `f` para tu torre.
- **Vienesa con `3.Bc4`**: el plan es el mismo que contra el Gambito de Rey con el alfil en `c4`, y hasta se llega a la misma posición: desarrollo, `...Bg4`, cambio en `f3` y el caballo a `d4`.

## Consejos
- En la Escocesa, `...Qf6` amenaza `f2`: mirá siempre si las blancas lo dejaron sin cuidar.
- Contra `5.Nxc6`, recapturá con el peón de `d`: tus alfiles quedan libres.
- Contra `5.Nb3` en la Escocesa, retirá el alfil a `b6`: sigue mirando `f2`.
- En el Gambito Vienés, no tomes en `f4`: el centro es más importante que el peón.
- En el Gambito Vienés, con la columna `f` abierta y las torres frente a frente, contá los jaques en la diagonal de `g1`: si el rey no puede apartarse sin dejar mate en la primera fila, la pieza que tape el jaque se pierde.

## Variante: Escocesa con 5.Nxc6 {#escocesa-nxc6} [básica]
Las blancas cambian caballos enseguida. Con `...Qf6` amenazás mate en `f2` y las blancas tienen que defenderse antes de seguir.

```pgn
1. e4 e5 2. Nf3 Nc6 3. d4 exd4 { [%hint Cambiá el peón que te atacan.] }
4. Nxd4 Bc5 { [%hint Desarrollá el alfil atacando al caballo central.] }
5. Nxc6 Qf6 { [%hint Antes de recapturar, amenazá mate en f2.] }
6. Qd2 dxc6 { [%hint Recapturá con el peón que les abre camino a tus piezas.] }
7. Nc3 Be6 8. Na4 Bd6 { El alfil se aparta del caballo y no se deja cambiar. }
9. Bd3 Qd4 { [%hint Centralizá la dama atacando al caballo del borde.] }
10. Nc3 O-O-O { [%hint Enrocá hacia el lado donde ya tenés la columna abierta.] }
11. Qe3 Qxe3+ 12. Bxe3 Nf6 13. h3 Nd7 { Desde d7 el caballo puede ir a c5 o a e5. }
14. f4 f6 { [%hint Controlá e5 con un peón para frenar el avance de su peón de e.] }
```

Final parejo y cómodo: tus piezas están desarrolladas y la columna `d` es tuya. Seguí con `...Rhe8` o `...h5`, sin apurarte.

## Variante: Escocesa con 5.Be3 {#escocesa-be3} [club]
Las blancas defienden el caballo con el alfil. Sumás presión sobre `d4` y armás tu juego con calma.

```pgn
1. e4 e5 2. Nf3 Nc6 3. d4 exd4 { [%hint Cambiá el peón que te atacan.] }
4. Nxd4 Bc5 { [%hint Desarrollá el alfil atacando al caballo central.] }
5. Be3 Qf6 { [%hint Sumá otra pieza contra el caballo de d4.] }
6. c3 Nge7 { [%hint Desarrollá el caballo sin tapar a tu dama.] }
7. Bc4 O-O 8. O-O Bb6 { [%hint Corré el alfil de la mira de las piezas blancas, sin dejar la diagonal.] }
9. Nc2 d6 10. Bxb6 axb6 { [%hint Recapturá con el peón que le abre una columna a tu torre.] }
11. f4 Be6 { [%hint Ofrecé cambiar al alfil blanco más activo.] }
```

Tu torre de `a8` ya trabaja en la columna abierta y el alfil de `e6` neutraliza al de `c4`. Mirá el peón de `a2`: si el alfil blanco se va de `c4`, `...Bxa2` lo gana.

## Variante: Gambito Vienés {#gambito-vienes} [básica]
Con `3.f4` las blancas juegan una especie de Gambito de Rey con el caballo ya en `c3`. No tomes: contragolpeá en el centro.

```pgn
1. e4 e5 2. Nc3 Nf6 { [%hint Desarrollá atacando el peón central.] }
3. f4 d5 { [%hint Contragolpeá en el centro en vez de tomar el peón.] }
4. fxe5 Nxe4 { [%hint Tu caballo está atacado: llevalo a una casilla donde recupere material y quede firme en el centro.] }
5. Nf3 Be7 6. d4 O-O { [%hint Poné el rey a salvo antes de abrir el juego.] }
7. Bd3 f5 { [%hint Sostené a tu caballo con un peón.] }
8. exf6 Bxf6 { Recapturás con el alfil, que ahora presiona d4. }
9. O-O Nc6 { [%hint Sumá otra pieza contra d4.] }
10. Nxe4 dxe4 11. Bxe4 Nxd4 { [%hint Recuperá el peón: si te toman el caballo, el jaque en d4 y tu torre de f8 ganan material.] }
12. c3 Nxf3+ 13. Bxf3 Qxd1 14. Rxd1 c6
```

Final parejo: el material está igualado y tus alfiles tienen buenas diagonales. Seguí con `...Bf5` y las torres a las columnas abiertas.

Después de `11...Nxd4` hay dos golpes blancos que conviene conocer. Si `12.Ng5`, jugá `12...Bf5` (no `12...Bxg5?`, por `13.Rxf8+ Qxf8 14.Bxg5`: tu caballo de `d4` queda atacado y sin defensa, y las blancas quedan claramente mejor). Si `12.Bxh7+?`, tomá: después de `12...Kxh7 13.Ng5+ Bxg5`, las blancas no tienen nada por la pieza.

## Variante: Vienesa con 3.Bc4 {#vienesa-bc4} [club]
Con `3.Bc4` las blancas apuntan a `f7` y suelen seguir con `d3` y `f4`. Desarrollás igual que contra el Gambito de Rey con el alfil en `c4`: llegás incluso a la misma posición.

```pgn
1. e4 e5 2. Nc3 Nf6 { [%hint Desarrollá atacando el peón central.] }
3. Bc4 Nc6 4. d3 Bc5 { [%hint Ubicá el alfil en la diagonal que apunta a f2.] }
5. f4 d6 { [%hint Sostené tu peón central con otro peón.] }
6. Nf3 Bg4 { [%hint Clavá al caballo contra la dama.] }
7. h3 Bxf3 8. Qxf3 Nd4 { [%hint Saltá con el caballo al centro con ganancia de tiempo.] }
9. Qg3 Qe7 10. fxe5 dxe5 11. Kd1 { El rey se corre para cuidar c2. }
c6 { [%hint Prepará la expansión del flanco de dama y quitale al rival la casilla d5.] }
```

Tu caballo de `d4` es muy fuerte y el rey blanco se quedó en el centro. Plan: `...b5` para echar al alfil de `c4` y `...Nh5` para molestar a la dama de `g3`.

## Trampa a favor: El jaque en d4 {#jaque-en-d4} [club]
En el Gambito Vienés, cuando las blancas recuperan el peón con el alfil en `e4`, tu caballo toma en `d4`. Comérselo parece natural, pero los jaques en la diagonal de `g1` y tu torre de `f8`, frente a la torre blanca de `f1`, ganan material.

```pgn
1. e4 e5 2. Nc3 Nf6 { [%hint Desarrollá atacando el peón central.] }
3. f4 d5 { [%hint Contragolpeá en el centro en vez de tomar el peón.] }
4. fxe5 Nxe4 { [%hint Tu caballo está atacado: llevalo a una casilla donde recupere material y quede firme en el centro.] }
5. Nf3 Be7 6. d4 O-O { [%hint Poné el rey a salvo antes de abrir el juego.] }
7. Bd3 f5 { [%hint Sostené a tu caballo con un peón.] }
8. exf6 Bxf6 9. O-O Nc6 { [%hint Sumá otra pieza contra d4.] }
10. Nxe4 dxe4 11. Bxe4 Nxd4 { [%hint Recuperá el peón: si te toman el caballo, el jaque en d4 y tu torre de f8 ganan material.] }
12. Nxd4?? { Parece ganar una pieza. }
Qxd4+ { [%hint Recapturá con jaque y atacá al mismo tiempo la pieza suelta.] Si 13.Kh1, Qxe4 y ganás el alfil. }
13. Qxd4 { Cambiar las damas parece salvar todo. }
Bxd4+ { Otra vez jaque, y el rey no puede apartarse: si 14.Kh1, Rxf1 es mate. La pieza que tape el jaque se pierde. }
14. Be3 Bxe3+
```

Ganaste una pieza. El patrón: con la columna `f` abierta y las torres enfrentadas, el rey blanco no puede esquivar un jaque en la diagonal de `g1` (`Kh1` permite `...Rxf1#`), así que la pieza que se interpone se pierde.
