## Para empezar
Contestás `1.e4` con `1...e5` y defendés el peón con `2...Nc6`. Si las blancas apuntan a f7 con `3.Bc4`, sacás el otro caballo: `3...Nf6` ataca el peón de e4 y te pone a jugar desde el principio.

- Desarrollá los caballos rápido: son tus primeras piezas.
- Vigilá f7: hasta que enroques, solo lo defiende tu rey.
- Si el caballo blanco salta a g5 para atacar f7, tapá la diagonal del alfil con `...d5`.
- Enrocá pronto y recién después pensá en atacar.

## Ideas y planes
- **Contra `4.Ng5`** el juego se vuelve un gambito: entregás un peón con `4...d5` y `5...Na5`, y a cambio ganás tiempos echando a las piezas blancas con `...c6`, `...h6` y `...e4`. Tu ventaja de desarrollo compensa el peón.
- **Contra `4.d3`** (la Italiana lenta) es una partida de maniobras: `...Bc5`, `...d6`, enroque, `...a6` para darle un refugio al alfil y `...h6` para que no te claven el caballo. La ruptura que libera tu juego es `...d5`.
- **Contra `4.Nc3`** hay un golpe táctico: `4...Nxe4` y, si te toman el caballo, `5...d5` ataca dos piezas a la vez y recuperás la pieza con un buen centro.
- **Contra `3.Bb5`** (la Española) jugás la Berlinesa: el mismo `3...Nf6`, y si enrocan te comés el peón de e4.
- **Contra `3.d4`** (la Escocesa) cambiás en d4 y atacás e4 con el caballo. Si cambian en c6 y avanzan e5, tu dama va a e7 y tu caballo a d5.

## Consejos
- Después de `4.Ng5 d5 5.exd5`, no recaptures con el caballo: es la puerta del Fried Liver.
- En la Italiana lenta, guardá el alfil en a7: desde ahí sigue mirando f2 y no te lo echan con d4.
- En la Defensa Polerio estás un peón abajo: no cambies piezas sin motivo, porque tu compensación es la actividad.
- Cuando tu alfil está en d6 y la dama blanca se para en d4 delante de la tuya, mirá si el alfil puede salir con jaque.
- Si en la Española no enrocan y juegan `4.d3`, sacá el alfil a c5 y jugá como en la Italiana lenta.

## Variante: Giuoco Pianissimo {#pianissimo} [básica]
Contra `4.d3` las blancas protegen e4 y eligen un juego lento. Vos desarrollás con naturalidad y armás una estructura parecida a la suya.

```pgn
1. e4 e5 2. Nf3 Nc6 3. Bc4 Nf6 { [%hint Desarrollá una pieza atacando el peón central que quedó sin defensa.] }
4. d3 Bc5 { [%hint Ubicá el alfil en la diagonal que apunta al punto débil del flanco de rey blanco.] }
5. c3 d6 { Sostenés e5 y abrís la diagonal de tu otro alfil. }
6. O-O O-O 7. Re1 a6 { [%hint Prepará un refugio para tu alfil antes de que lo ataquen los peones blancos.] }
8. Bb3 Ba7 9. h3 h6 { [%hint Impedí que un alfil blanco clave a tu caballo de f6.] }
10. Nbd2 Re8 11. Nf1 Be6 { [%hint Ofrecé el cambio del alfil blanco más peligroso.] }
```

Si las blancas no cambian en e6 y retiran el alfil, la jugada típica es `...d5`: ganás espacio y liberás tu juego. Mientras tanto, el alfil de a7 sigue presionando f2.

## Variante: Truco del tenedor {#truco-del-tenedor} [básica]
Contra `4.Nc3` conviene conocer un golpe: entregás el caballo por el peón de e4 y lo recuperás enseguida con un tenedor de peón.

```pgn
1. e4 e5 2. Nf3 Nc6 3. Bc4 Nf6 4. Nc3 Nxe4 { [%hint Un peón tuyo puede atacar dos piezas a la vez: prepará ese golpe.] }
5. Nxe4 d5 { [%hint Atacá dos piezas con un solo peón.] Tenedor: el peón ataca al alfil y al caballo. [%cal Gd5c4,Gd5e4] }
6. Bd3 dxe4 7. Bxe4 Bd6 { [%hint Defendé el peón de e5 con una pieza que además apunte al flanco de rey blanco.] }
8. d4 exd4 { Cambiás y las blancas se quedan sin peones en el centro. }
9. O-O O-O
```

Igualaste con comodidad: tus piezas salen fácil y el caballo de c6 defiende el peón de d4. Si las blancas lo quieren recuperar con `10.Nxd4 Nxd4 11.Qxd4`, `11...Bxh2+` gana la dama: es la misma idea de la trampa de esta ficha.

## Variante: Defensa Polerio {#polerio} [club] [gambito]
`4.Ng5` ataca f7 con dos piezas. Lo tapás con `4...d5` y, después de `5.exd5`, no recapturás (eso lleva al Fried Liver): atacás al alfil con `5...Na5`. Entregás un peón, pero ganás muchos tiempos.

```pgn
1. e4 e5 2. Nf3 Nc6 3. Bc4 Nf6 4. Ng5 d5 { [%hint Cortá la diagonal del alfil que apunta a f7.] }
5. exd5 Na5 { [%hint No recuperes el peón: echá a la pieza que apunta a tu punto débil.] El caballo va al borde, pero el alfil tiene que moverse otra vez. }
6. Bb5+ c6 7. dxc6 bxc6 8. Be2 h6 { [%hint Echá al caballo que se metió en tu campo.] }
9. Nf3 e4 { [%hint Seguí ganando tiempos contra el mismo caballo.] }
10. Ne5 Bd6 { Desarrolla y ataca al caballo de e5. }
11. d4 exd3 { Captura al paso: abrís líneas para tus piezas. }
12. Nxd3 Qc7 { [%hint Armá una batería que apunte al flanco de rey blanco.] La dama y el alfil miran a h2. }
```

Estás un peón abajo, pero tus piezas están mucho más activas y las blancas tienen que enrocar con cuidado, porque h2 está en la mira. Seguí con el enroque corto y con `...Bf5` o `...Re8`.

## Variante: Defensa Berlinesa {#berlinesa} [club]
Contra la Española (`3.Bb5`) usás la misma idea que contra la Italiana: `3...Nf6` ataca e4. Si las blancas enrocan sin defenderlo, te lo comés.

```pgn
1. e4 e5 2. Nf3 Nc6 3. Bb5 Nf6 { [%hint Atacá el peón central, igual que contra el alfil en c4.] }
4. O-O Nxe4 { Las blancas no lo defendieron: lo tomás y después ellas recuperan el peón. }
5. Re1 Nd6 { [%hint Retirá el caballo atacado a una casilla donde también amenace algo.] El caballo ataca al alfil de b5. }
6. Nxe5 Be7 { [%hint Tapá la columna abierta antes de que tu rey quede expuesto.] }
7. Bf1 Nxe5 8. Rxe5 O-O { Tu rey ya está a salvo y la posición es pareja. }
9. d4 Bf6 { [%hint Echá a la torre del centro con ganancia de tiempo.] }
10. Re1 Re8 { Ofrecés cambiar torres en la columna abierta. }
```

Posición simétrica y sólida. Si las blancas no cambian torres, cambiá vos en e1. Después el caballo de d6 se reubica (f5 es una buena casilla) y los peones de c y d salen para liberar el alfil de c8.

## Variante: Escocesa, Variante Mieses {#escocesa} [club]
Contra `3.d4` cambiás en d4 y atacás el peón de e4 con el caballo. La respuesta más directa de las blancas es cambiar en c6 y avanzar `6.e5`.

```pgn
1. e4 e5 2. Nf3 Nc6 3. d4 exd4 4. Nxd4 Nf6 { [%hint Desarrollá una pieza atacando el peón central.] }
5. Nxc6 bxc6 { [%hint Recapturá hacia el centro.] }
6. e5 Qe7 { [%hint Clavá el peón que avanzó contra el rey blanco.] Si el peón come al caballo, la columna e queda abierta hasta el rey blanco: no puede. }
7. Qe2 Nd5 { El caballo encuentra una buena casilla en el centro. }
8. c4 Ba6 { [%hint Clavá el peón que ataca a tu caballo.] Si el peón come en d5, se pierde la dama de e2. }
9. b3 g6 { [%hint Prepará el lugar para el alfil que va a presionar e5.] }
10. g3 Bg7 11. Bb2 O-O
```

Tu plan es presionar e5 con las torres (`...Rae8` o `...Rfe8`) y abrir con `...d6` o `...f6`. Ojo: si la dama blanca se va de e2, el peón de c4 deja de estar clavado y tu caballo de d5 tiene que moverse.

## Trampa en contra: Ataque Fegatello (Fried Liver) {#fried-liver} [básica]
Después de `4.Ng5 d5 5.exd5`, recapturar con el caballo parece lo más lógico. Es justo lo que esperan las blancas.

```pgn
1. e4 e5 2. Nf3 Nc6 3. Bc4 Nf6 4. Ng5 d5 5. exd5 Na5 { [%hint No recuperes el peón: echá a la pieza que apunta a tu punto débil.] }
(5... Nxd5? { Parece natural, pero deja a tu rey sin defensores. } 6. Nxf7 { El caballo se sacrifica para sacar a tu rey de su casa. } Kxf7 7. Qf3+ { Jaque y ataque al caballo de d5. La mejor defensa es llevar el rey a e6, pero aun así queda en el medio del tablero y el ataque blanco es muy peligroso. } Kg8?? { Volver a casa parece lo más seguro. } 8. Bxd5+ Qxd5 9. Qxd5+ Be6 10. Qxe6#)
```

Recordá la regla: contra `4.Ng5`, primero `4...d5` y después `5...Na5`. Lo que sigue lo tenés en la Defensa Polerio.

## Trampa a favor: La descubierta en h2 {#descubierta-en-h2} [club]
En el truco del tenedor, tu alfil de d6 y tu dama comparten la columna d. Si las blancas enrocan, empujan d4 y terminan recapturando con la dama en d4, el alfil sale con jaque y la deja colgando.

```pgn
1. e4 e5 2. Nf3 Nc6 3. Bc4 Nf6 4. Nc3 Nxe4 5. Nxe4 d5 6. Bd3 dxe4 7. Bxe4 Bd6
8. O-O O-O 9. d4 Nxd4 10. Nxd4 exd4 11. Qxd4?? { Recupera el peón, pero la dama queda en la columna d, detrás de tu alfil. }
Bxh2+ { [%hint Sacá con jaque la pieza que tapa la columna de tu dama.] Jaque al rey y, al mismo tiempo, tu dama ataca a la blanca. }
12. Kxh2 Qxd4
```

Diste un alfil y ganaste la dama. Recordá el patrón: alfil en d6, dama en d8 y la dama rival en la misma columna, delante de las dos.
