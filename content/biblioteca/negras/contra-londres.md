## Para empezar
El que juega el Londres saca el alfil a f4 y arma casi siempre lo mismo: e3, c3, Nf3, Nbd2 y Bd3. Esa comodidad tiene un costo: el alfil se fue de c1 y **el peón de b2 quedó sin defensor**. Por eso golpeás el centro con `2...c5` y, cuando sea seguro, llevás la dama a b6.

- Golpeá d4 con c5 y desarrollá el caballo a c6.
- Sacá el caballo de g8 a f6 antes de llevar la dama a b6.
- La dama va a b6 recién cuando las blancas jugaron c3: antes, el caballo blanco puede saltar a c3 y de ahí a b5.
- Si las blancas cambian en c5, recuperá el peón con el alfil.

## Ideas y planes
- **La presión sobre b2**: con tu dama en b6, las blancas tienen que gastar tiempo en defender ese peón, con la dama o con b3.
- **El avance `...c4`**: cuando la dama blanca va a b3, empujar c4 la echa con tiempo y te gana espacio en el flanco de dama.
- **El alfil de c8 antes de e6**: como en la Eslava, sacalo a f5 antes de cerrar la cadena con e6.
- **El alfil de f4** es la pieza preferida del Londres: si podés, cambialo. El caballo que va a h5 lo persigue y `...Bd6` le ofrece el cambio.
- **Si las blancas cambian en d4**: con `5.Nbd2 cxd4 6.exd4` la estructura queda simétrica y tranquila; desarrollá y cambiá alfiles con `...Bd6`.

## Consejos
- Nunca saques la dama a b6 si el caballo blanco puede ir a c3 y después a b5: el peón de b2 es una carnada.
- Con la dama blanca en c2, el alfil a f5 la ataca con tiempo, pero hacelo solo si tu caballo de f6 ya cuida d5.
- Si las blancas cambian las damas en b6, recapturá con el peón: la columna a se abre para tu torre.
- Cuando las blancas tienen la columna h abierta, pensalo dos veces antes de enrocar corto.

## Variante: Con c3: la dama a b6 {#c3-dama-b6} [básica]
El esquema más común del Londres. Cuando las blancas juegan c3, la dama a b6 ya es segura y ataca b2.

```pgn
1. d4 d5 2. Bf4 c5 { [%hint Golpeá el peón de d4 con un peón de flanco.] }
3. e3 Nc6 4. Nf3 Nf6 { [%hint Desarrollá antes de sacar la dama.] }
5. c3 Qb6 { [%hint Ahora que el caballo blanco ya no puede ir a c3, atacá el peón que el alfil dejó sin defensa.] }
6. Qb3 c4 { [%hint Echá a la dama con un avance que te gane espacio.] }
7. Qc2 Bf5 { [%hint Desarrollá con ataque a la dama.] }
8. Qc1 e6 9. Nbd2 Nh5 { [%hint Perseguí a la pieza más importante del Londres.] }
10. Bg3 Nxg3 11. hxg3 Be7
```

Cambiaste el alfil de f4 y tu peón de c4 te da espacio en el flanco de dama. Si las blancas lo atacan con b3, cambiá en b3 para abrir la columna c a tus torres. Como la columna h quedó semiabierta para la torre blanca, no apures el enroque corto.

## Variante: Con c3 y cambio de damas {#cambio-de-damas} [básica]
Si las blancas cambian las damas en b6, llegás a un final cómodo con más espacio en el flanco de dama.

```pgn
1. d4 d5 2. Bf4 c5 3. e3 Nc6 4. Nf3 Nf6 { [%hint Desarrollá antes de sacar la dama.] }
5. c3 Qb6 { [%hint Ahora que el caballo blanco ya no puede ir a c3, atacá el peón que el alfil dejó sin defensa.] }
6. Qb3 c4 { [%hint Echá a la dama con un avance que te gane espacio.] }
7. Qxb6 axb6 { [%hint Recapturá de manera que tu torre gane una columna.] }
8. Nbd2 b5 { [%hint Ganá espacio en el flanco de dama con tus peones doblados.] }
9. a3 Bf5 { [%hint Sacá el alfil de casillas claras antes de cerrar con e6.] }
10. Be2 e6 11. O-O h6 { Le das al alfil la casilla h7 para cuando un caballo lo persiga desde h4. } 12. Rfe1 Be7
```

Final parejo, con más espacio para vos en el flanco de dama. Sin damas, tu rey puede ir a d7 o enrocar sin miedo; el plan es preparar `...b4` para abrir una columna en el flanco donde sos más fuerte.

## Variante: Con Nbd2: cambio en d4 {#nbd2} [básica]
Si las blancas sacan el caballo a d2 antes de jugar c3, cambiás en d4 y la posición se vuelve simétrica.

```pgn
1. d4 d5 2. Bf4 c5 3. e3 Nc6 4. Nf3 Nf6 { [%hint Desarrollá antes de sacar la dama.] }
5. Nbd2 cxd4 { [%hint Cambiá en el centro antes de que las blancas completen su esquema.] }
6. exd4 Bf5 { [%hint Sacá el alfil de casillas claras antes de cerrar con e6.] }
7. c3 e6 8. Be2 Bd6 { [%hint Ofrecé el cambio de la pieza preferida del Londres.] }
9. Bxd6 Qxd6 10. O-O O-O
```

Estructura simétrica y sin problemas. Seguí con `...Rac8` y `...Rfe8`. Si un caballo blanco va a h4 para cambiar tu alfil, no pasa nada: recapturás con el peón de e y la columna e queda para tus torres.

## Variante: Si las blancas cambian en c5 {#dxc5} [básica]
Tomar en c5 es una forma de evitar tu presión. Recuperás el peón con el alfil y te quedás con un buen centro.

```pgn
1. d4 d5 2. Bf4 c5 3. dxc5 e6 { [%hint Abrí la diagonal del alfil que va a recuperar el peón.] }
4. e3 Bxc5 5. Nf3 Nf6 6. Bd3 Nc6 7. O-O O-O 8. Nbd2 Qe7
```

Recuperaste el peón y tus piezas están bien ubicadas. El plan es preparar `...e5` con `...Rd8`: ese avance le saca espacio al alfil de f4 y libera tu juego.

## Trampa en contra: La dama a b6 antes de tiempo {#dama-antes-de-tiempo} [básica]
Si sacás la dama a b6 cuando las blancas todavía no jugaron c3, el caballo blanco salta a c3 y amenaza entrar en b5, donde ataca c7 junto con el alfil de f4.

```pgn
1. d4 d5 2. Bf4 c5 3. e3 Nc6 4. Nf3 Nf6 { [%hint Desarrollá antes de sacar la dama.] }
(4... Qb6? { Parece molestar a b2, pero la casilla c7 queda floja. } 5. Nc3 { Ofrece el peón de b2. } Qxb2 6. Nb5 { Amenaza Nc7+, que ataca a la vez al rey y a la torre, y además Rb1 para perseguir a tu dama: vas a perder material. })
5. c3 Qb6 { [%hint Ahora que el caballo blanco ya no puede ir a c3, atacá el peón que el alfil dejó sin defensa.] }
```

Con el caballo en f6 y el peón blanco en c3, la dama en b6 ya no corre peligro.

## Trampa a favor: La dama que se come el alfil {#dama-come-alfil} [básica]
Con la dama blanca en c2, tu alfil sale a f5 con ataque. Si las blancas lo comen, tu dama se lleva b2 y después la torre de a1.

```pgn
1. d4 d5 2. Bf4 c5 3. e3 Nc6 4. Nf3 Nf6 5. c3 Qb6 6. Qb3 c4 7. Qc2 Bf5
8. Qxf5?? { Gana el alfil, pero abandona la defensa de b2. } Qxb2 { [%hint Volvé sobre el punto que la dama blanca dejó de cuidar.] }
9. Be2 e6 { [%hint Echá a la dama blanca antes de cobrar la torre.] } 10. Qh3 Qxa1
```

Ganaste una torre y un peón a cambio del alfil. Fijate por qué funciona: tu caballo de f6 defiende d5. Sin él, después de `Qxf5 Qxb2` la dama blanca se come ese peón y la cuenta cambia a favor de las blancas.

## Trampa a favor: Sostener el peón con b4 {#b4-y-dama-f6} [club]
Cuando las blancas cambian en c5, a veces intentan quedarse con el peón empujando b4. Esa jugada abre la diagonal hasta a1, y el alfil de f4 está sin protección porque todavía no jugaron e3.

```pgn
1. d4 d5 2. Bf4 c5 3. dxc5 e6 { [%hint Abrí la diagonal del alfil que va a recuperar el peón.] }
4. b4? { Sostiene el peón, pero abre la diagonal larga. } Qf6 { [%hint Atacá a la vez dos piezas que nadie defiende.] }
5. c3 Qxf4 { [%hint Cobrá la pieza que quedó sola.] }
```

Ganaste un alfil limpio. La idea para recordar: el alfil del Londres sin el peón de e3 detrás queda colgando, y una dama en f6 lo ataca junto con la torre de a1.
