## Para empezar
Con `2.f4` las blancas ofrecen un peón para abrir la columna `f` y dominar el centro. Vos no lo aceptás: `2...Bc5` lleva el alfil a una diagonal que apunta a `g1`, la casilla del enroque blanco.

- No tomes en `f4`: con tu alfil en `c5`, las blancas no pueden enrocar corto con comodidad.
- Si las blancas se comen tu peón enseguida (`3.fxe5??`), tenés `3...Qh4+` y ganás una torre.
- Defendé `e5` con `...d6` y desarrollá con `...Nf6` y `...Nc6`.
- Si te atacan el alfil con `c3` y `d4`, retiralo a `b6`: sigue mirando `g1`.

## Ideas y planes
- **Contra `4.c3`** las blancas preparan `d4`. Si lo juegan, cambiás en `d4`, retirás el alfil a `b6` y apuntás todo al peón de `d4`, que ya no tiene un peón de `c` que lo defienda: con `...Nc6`, `...Re8`, `...Ng4` y `...Bg4` le sacás los defensores uno por uno.
- **Si toman en `e5` con `5.fxe5`**, recapturás y, si el caballo se come el peón, `...Qe7` lo ataca y recuperás el peón de `e4` con buen juego.
- **Contra el alfil en `c4`** el juego es más tranquilo: desarrollás, cambiás tu alfil de `g4` por el caballo de `f3` y llevás el caballo a `d4`, donde amenaza `c2`.
- La diagonal `a7-g1` es tu arma: mientras tu alfil la ocupe, el rey blanco no tiene un lugar cómodo.

## Consejos
- Con la dama blanca en `f3`, `...Nd4` llega con ganancia de tiempo y además amenaza `c2`.
- Cuando la dama blanca va a `g3` y amenaza `g7`, no te apures a comer en `c2`: le das a las blancas un ataque peligroso contra tu rey.
- Si las blancas cambian en `e5` con el alfil en `c4` y después se comen el peón con el caballo, `...Qd4` castiga la jugada.
- No cambies tu alfil de `c5` sin motivo: es la pieza que molesta al rey blanco.
- Si las blancas enrocan sin cuidar `d4`, mirá si `...Nxd4` gana el peón con un jaque de tu alfil.

## Variante: Clásica con 4.c3 {#cuatro-c3} [básica]
La respuesta más ambiciosa: las blancas preparan `d4` para echar a tu alfil y quedarse con el centro.

```pgn
1. e4 e5 2. f4 Bc5 { [%hint Desarrollá el alfil a la diagonal que apunta a la casilla del enroque blanco.] }
3. Nf3 d6 { [%hint Sostené tu peón central con otro peón.] }
4. c3 Nf6 5. d4 exd4 6. cxd4 Bb6 { [%hint Retirá el alfil sin abandonar la diagonal.] }
7. Bd3 Nc6 { [%hint Atacá al peón central que se quedó sin el apoyo de otro peón.] }
8. Nc3 O-O 9. Be3 Re8 { [%hint Poné la torre frente al rey blanco.] }
10. O-O Ng4 { [%hint Cambiá al alfil que defiende d4.] }
11. Qe2 Nxe3 12. Qxe3 Bg4 { [%hint Atacá al caballo que defiende d4.] }
```

Las blancas no pueden sostener `d4` para siempre: con `...Bxf3` y `...Bxd4` ganás un peón y quedás mejor. Ojo con un detalle de la jugada 9: si las blancas enrocan en vez de jugar `Be3`, `9...Nxd4` gana un peón, porque `10.Nxd4` permite el jaque `10...Bxd4+`.

## Variante: Toma en e5 {#toma-en-e5} [club]
Con `5.fxe5` las blancas abren la columna `f`. Si el caballo se come el peón, lo recuperás enseguida.

```pgn
1. e4 e5 2. f4 Bc5 { [%hint Desarrollá el alfil a la diagonal que apunta a la casilla del enroque blanco.] }
3. Nf3 d6 { [%hint Sostené tu peón central con otro peón.] }
4. c3 Nf6 5. fxe5 dxe5 6. Nxe5 Qe7 { [%hint Atacá al caballo que se comió tu peón.] }
7. d4 Bd6 { [%hint Volvé a atacar al caballo con una pieza que se desarrolla.] }
8. Nf3 Nxe4 { Recuperaste el peón y tu caballo domina el centro. }
9. Be2 O-O 10. O-O Bg4
```

Material parejo y piezas activas. Seguí con `...c5` para atacar el centro; si las blancas cambian tu caballo de `e4`, recapturá y seguí con el mismo plan.

## Variante: Con el alfil en c4 {#alfil-c4} [básica]
Las blancas desarrollan con `4.Bc4` apuntando a `f7`. El juego se parece a una Italiana con el peón de `f` ya avanzado.

```pgn
1. e4 e5 2. f4 Bc5 { [%hint Desarrollá el alfil a la diagonal que apunta a la casilla del enroque blanco.] }
3. Nf3 d6 { [%hint Sostené tu peón central con otro peón.] }
4. Bc4 Nf6 5. d3 Nc6 6. Nc3 Bg4 { [%hint Clavá al caballo contra la dama.] }
7. h3 Bxf3 8. Qxf3 Nd4 { [%hint Saltá con el caballo al centro con ganancia de tiempo.] }
9. Qg3 Qe7 10. fxe5 dxe5 11. Kd1 { El rey se corre para cuidar c2. }
c6 { [%hint Prepará la expansión del flanco de dama y quitale al rival la casilla d5.] }
```

Tu caballo de `d4` es muy fuerte y el rey blanco se quedó en el centro. Plan: `...b5` para echar al alfil de `c4` y `...Nh5` para molestar a la dama de `g3`.

## Trampa a favor: El jaque en h4 {#jaque-en-h4} [básica]
Es la razón por la que `2...Bc5` funciona: si las blancas toman en `e5` sin pensar, tu dama entra por la diagonal que abrió el peón de `f`.

```pgn
1. e4 e5 2. f4 Bc5 { [%hint Desarrollá el alfil a la diagonal que apunta a la casilla del enroque blanco.] }
3. fxe5?? { Parece ganar un peón gratis. }
Qh4+ { [%hint Dale jaque al rey por la diagonal que abrió el peón de f.] }
4. g3 { Si 4.Ke2, Qxe4 es mate. }
Qxe4+ { [%hint Atacá al mismo tiempo al rey y a la torre del rincón.] }
5. Qe2 Qxh1
```

Ganaste una torre. Tu dama puede seguir comiendo, pero vigilá que no quede encerrada en el rincón: sacala en cuanto puedas.

## Trampa a favor: La dama en d4 {#dama-en-d4} [club]
Cuando el alfil blanco está en `c4`, comerse tu peón de `e5` con el caballo es un error: la dama aparece en `d4` con un ataque doble.

```pgn
1. e4 e5 2. f4 Bc5 { [%hint Desarrollá el alfil a la diagonal que apunta a la casilla del enroque blanco.] }
3. Nf3 d6 { [%hint Sostené tu peón central con otro peón.] }
4. Bc4 Nf6 5. fxe5 dxe5 6. Nxe5?? { Se come un peón, pero deja f2 sin cuidar. }
Qd4 { [%hint Centralizá la dama: amenazá mate en f2 y atacá dos piezas a la vez.] }
7. Nd3 { Cubre f2 y ataca a tu alfil, pero el alfil de c4 queda colgado. }
Qxc4 8. Nxc5 Qxc5
```

Ganaste una pieza por un peón. El patrón: tu alfil en `c5` apuntando a `f2`, y una pieza blanca sin defensa en `c4`. Desde `d4`, la dama ataca todo a la vez.
