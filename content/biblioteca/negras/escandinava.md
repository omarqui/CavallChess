## Para empezar
Con `1...d5` atacás el peón de e4 de inmediato. Lo más común es `2.exd5`, y vos recuperás el peón con la dama. Es cierto que la dama sale temprano y el caballo blanco la ataca con `3.Nc3`, pero en a5 está segura y molesta: apunta a lo largo de la quinta fila y va a clavar ese caballo en cuanto se mueva el peón d.

Después armás una estructura muy fácil de recordar: peones en c6 y e6, alfil afuera en f5 **antes** de jugar ...e6, caballos en f6 y d7 y enroque. Contra `2.Nc3` y `2.e5` tenés planes propios, más abajo.

## Ideas y planes
- La estructura c6–e6 no tiene debilidades: si te desarrollás bien, el blanco tiene un poco más de espacio y nada más.
- El alfil de c8 tiene que salir a f5 antes de ...e6; si no, queda encerrado como en la Francesa.
- Cuidá tu dama de los ataques a la descubierta: con el alfil blanco en d2, cualquier salto del caballo de c3 la ataca.
- Si el blanco te persigue el alfil con Ne5, g4 y h4, cambiale ese caballo y buscá cambiar los alfiles de casillas claras.
- Contra `2.Nc3` avanzás con ...d4 y ganás espacio; contra `2.e5` jugás como en la Francesa, pero con el alfil de casillas claras afuera.

## Consejos
- Antes de mover, preguntate si tu dama en a5 queda atacada cuando se mueva el caballo de c3.
- Sacá el alfil a f5 antes de cerrar con ...e6.
- Si el blanco juega Bc4 y Ne5, defendé f7 antes de sacar el caballo de b8.
- No tomes un caballo que aparece en d5 sin mirar qué hay detrás.

## Variante: Principal con 3...Qa5 {#principal-qa5} [básica]
La línea más común. Te desarrollás con ...c6, ...Bf5, ...Nbd7 y ...e6, y sacás la dama de a5 a tiempo.

```pgn
1. e4 d5 2. exd5 Qxd5 { [%hint Recuperá el peón enseguida.] } 3. Nc3 Qa5 { [%hint Apartá la dama a una casilla segura que mire al caballo de c3: lo va a clavar en cuanto se mueva el peón d.] } 4. d4 Nf6 5. Nf3 c6 { [%hint Dale a la dama una retirada y controlá b5 y d5.] } 6. Bc4 Bf5 { [%hint Sacá el alfil antes de cerrar la cadena.] } 7. Bd2 { Amenaza Nd5 con descubierta sobre tu dama. } Nbd7 { [%hint Desarrollá un caballo que pueda retomar en f6 si el blanco cambia allí; recién después cerrá con ...e6.] Con este orden, si viene 8.Nd5 Qd8 9.Nxf6+, retomás con el caballo. Sin él en d7, tendrías que retomar con la dama, que ya se movió tres veces, o con un peón, que te estropea la estructura. Y si 8.Qe2, jugá 8...Qc7 antes de ...e6 (8...e6? 9.d5!). } 8. O-O e6 9. Re1 Qc7 { [%hint Con la torre en e1 amenazan d5: sacá la dama de a5 antes de desarrollar el alfil.] Si 9...Be7?, 10.d5 abre el centro con tu rey todavía en e8. }
```

Seguí con ...h6 (para guardar el alfil en h7 si viene Nh4), ...Be7 o ...Bd6 y enroque corto. Tu estructura es muy sólida y el blanco no tiene un plan claro para romperla.

## Trampa en contra: La descubierta en d5 {#descubierta-en-d5} [básica]
Con el alfil blanco en d2, el caballo de c3 puede saltar a d5 y destapar un ataque a tu dama. El caballo parece regalado, pero no lo es.

```pgn
1. e4 d5 2. exd5 Qxd5 3. Nc3 Qa5 4. d4 Nf6 5. Nf3 c6 6. Bc4 Bf5 7. Bd2 Nbd7 8. Nd5 { El caballo se ofrece y destapa el alfil de d2 contra tu dama. } Qd8! { [%hint Tu dama está atacada aunque no lo parezca: salvala primero.] } (8... cxd5?? { Te comés un caballo... } 9. Bxa5 { ...y perdés la dama. }) 9. Nxf6+ Nxf6 10. Qe2 e6
```

Después del cambio en f6 la posición está igualada: terminá el desarrollo con ...Be7 o ...Bd6 y enrocá.

## Variante: El ataque Ne5 y g4 {#ataque-ne5-g4} [club]
Un plan agresivo y muy jugado: el caballo va a e5 para atacar f7 y los peones del flanco de rey persiguen a tu alfil. Hay que conocer el camino exacto.

```pgn
1. e4 d5 2. exd5 Qxd5 3. Nc3 Qa5 4. d4 Nf6 5. Nf3 c6 6. Bc4 Bf5 7. Ne5 { Ataca f7 junto con el alfil de c4. } e6 { [%hint Cubrí f7: tu caballo de b8 todavía no puede salir.] Con 7...Nbd7?? el blanco juega 8.Bxf7+ y gana. } 8. g4 Bg6 9. h4 Nbd7 { [%hint Atacá el caballo que sostiene todo el ataque.] } 10. Nxd7 Nxd7 11. h5 Be4 { [%hint Tu alfil necesita salir de la red: buscá una casilla desde donde ataque.] Cualquier otra jugada pierde material: si enrocás o sacás el alfil de f8, hxg6 gana una pieza. } 12. Rh3 { Si 12.f3, jugá 12...Bd5 enseguida. } Bg2 13. Re3 Bd5 { [%hint Ofrecé el cambio del alfil que más te molesta.] }
```

Si el blanco cambia en d5, recapturá con el peón de c y usá la columna c abierta con ...Rc8. Tu rey puede quedarse en el centro un rato: los peones del blanco avanzaron mucho y su rey tampoco está cómodo.

## Variante: Contra 2.Nc3 {#contra-2-nc3} [básica]
El blanco no cambia en d5 y desarrolla el caballo. Vos avanzás el peón y ganás espacio con tiempo.

```pgn
1. e4 d5 2. Nc3 d4 { [%hint Ganá espacio echando al caballo.] } 3. Nce2 { Si 3.Nb5, con 3...a6 lo echás y tiene que irse a a3. } e5 4. Ng3 Be6 { [%hint Desarrollá el alfil cubriendo f5, la casilla que busca el caballo de g3.] } 5. Nf3 f6 { Sostiene e5 con un peón y deja libres tus piezas. } 6. Bb5+ c6 7. Be2 Qd7 8. d3 g6 9. O-O c5
```

Con peones en c5, d4 y e5 tenés mucho espacio en el centro y en el flanco de dama. Seguí con ...Nc6 y completá el desarrollo antes de decidir dónde enrocar.

## Variante: Contra 2.e5 {#contra-2-e5} [básica]
El blanco avanza y la posición se parece a la Francesa, pero con una gran diferencia: tu alfil de c8 sale antes de cerrar con ...e6.

```pgn
1. e4 d5 2. e5 Bf5 { [%hint Sacá el alfil antes de cerrar la cadena con el peón e.] } 3. d4 e6 4. Nf3 c5 { [%hint Atacá la base de la cadena blanca.] } 5. c3 Nc6 6. Be2 cxd4 7. cxd4 Nge7 { [%hint Prepará más presión sobre d4 con el caballo del rey.] } 8. O-O Be4 { Le deja f5 al caballo. } 9. Nc3 Nf5
```

Tus piezas presionan d4 desde c6 y f5. Con ...Be7, enroque y ...Rc8 tenés un juego cómodo; si el blanco descuida d4, lo ganás.
